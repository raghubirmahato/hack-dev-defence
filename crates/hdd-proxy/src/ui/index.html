    What this build does and does not claim

    • It inspects request vectors for SQL-injection shapes and blocks them when a site is in block mode.
    • It records what it saw: rule family, vector, field, redacted evidence and a Ray ID.
    • A site is not protected while it can be bypassed: block mode needs a verified origin lockdown (R-34).
    • Detection is measured against its fixtures; it is not a completeness claim and there is no absolute protection.
    • Request bodies are never logged in full and evidence is redacted and capped.
    • TLS is terminated by Caddy, Cloudflare or nginx in front of the proxy; the proxy itself is HTTP on loopback.

    HDD Hack Dev Defence demo build. The UI never fabricates numbers, sample rows or protection claims: empty and unverified states are shown as such.
