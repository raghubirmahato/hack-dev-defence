### T-0103 · Sitemap, robots, canonical URLs, metadata and caching for public pages
`P05` `[UI][OPS]` · deps: T-0095 · size: S · owner: ui
**Objective.** Make the public site discoverable and fast without third-party tools.
**Steps.**
1. Generate `sitemap.xml` from public routes and docs pages with `lastmod` from content dates; `robots.txt` allowing public pages and disallowing app/admin/api surfaces and `/__hdd/`.
2. Implement canonical URL tags, hreflang for shipped locales, and consistent trailing-slash redirects.
3. Generate Open Graph cards per major page at build time (reusing the brand template).
4. Set caching: public pages `Cache-Control: public, max-age=300, stale-while-revalidate=3600` and ETags; compressed responses.
5. Implement 404 handling that returns helpful links and does not index.
6. Add minimal structured data (Organization, WebSite) only if the operator provides entity details.
7. Add a link between the public site and the status/docs without third-party widgets.
8. Add tests verifying that app/admin hosts return `noindex` and disallowed robots.
**Deliverables.**
- generators, routes, tests
**Acceptance.**
- A1: sitemap lists only public pages and validates.
- A2: app/admin/api hosts return `X-Robots-Tag: noindex`.
- A3: every public page has a canonical URL and valid metadata.
- A4: compression and caching headers are correct (header test).
- A5: no tracking or third-party tags exist (network trap).
**Tests.**
- Unit/integration header tests; sitemap validation.
**Notes.** SEO is secondary to accuracy and accessibility.
