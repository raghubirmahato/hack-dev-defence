### T-0087 · Table infrastructure: cursor pagination, URL state, saved views, CSV export
`P04` `[UI][API]` · deps: T-0044, T-0079 · size: M · owner: ui
**Objective.** Standardize list behavior across the product.
**Steps.**
1. Implement opaque cursor pagination (signed, versioned cursors encoding sort key and last seen values) with `limit` caps, stable ordering with tie-breakers, and total-count approximation labels where counts are expensive.
2. Implement filter/sort state in the URL with a typed query model per table (unknown keys rejected, values validated), generating canonical URLs and breadcrumbs for "clear filters".
3. Implement saved views (per user, per screen, per org): CRUD, name uniqueness, default view, share with org (admin permission), schema-versioned filter JSON validated against the table's model.
4. Implement CSV/NDJSON export streaming with backpressure, row limits per plan, and formula-injection protection (prefix `'` to cells starting with `=`, `+`, `-`, `@`, tab, CR), correct escaping, and BOM option.
5. Implement column visibility and density persistence (account preference per table).
6. Implement bulk selection across pages ("select all N matching" with server-side confirmation) with safeguards (confirm count).
7. Document how to add a new table (model, columns, filters, export).
8. Add tests with large datasets (100k rows) for performance of keyset pagination.
**Deliverables.**
- `crates/hdd-web/src/tables/*`, saved-view tables (migration in P06 `[DB]` task), docs
**Acceptance.**
- A1: tampered or expired cursors return a clear error without leaking structure.
- A2: CSV exports neutralize formula injection (test vector set from ATK-047, ATK-300).
- A3: the same filters produce the same URL regardless of parameter order.
- A4: keyset pagination meets the performance target (p95 under 50 ms for 100k rows in Postgres on the builder).
- A5: bulk select-all shows the count and requires confirmation.
**Tests.**
- Unit: cursor sign/verify tables, URL canonicalization; proptest for round trips.
- Integration: Postgres keyset tests via testcontainers; export streaming memory test.
- Fuzz: cursor decoder never panics.
**Notes.** Saved views storage lands with the identity migrations to avoid a second migration series.
