### T-0088 · SVG chart renderer in Rust
`P04` `[UI]` · deps: T-0046, T-0074 · size: XL · owner: ui
**Objective.** Implement the chart family as pure functions producing accessible SVG.
**Steps.**
1. Decide between a vetted crate and a small custom writer (ADR): requirements are deterministic output, no JavaScript, no external fonts, and tiny code.
2. Implement shared primitives: scales (linear, time, band), tick generation (nice numbers, time ticks respecting the user zone), axis and gridline renderers, label thinning, text measurement approximation, clipping, null/gap handling.
3. Implement chart types: line, area, bar, stacked bar, horizontal ranked bar, donut, sparkline, heatmap (hour by day), and the choropleth map with the simplified geometry from T-0046.
4. Implement series differentiation: color tokens plus patterns/dashes, legends with direct labels where space permits, and annotation markers (vertical lines with labels) for mode/rule changes.
5. Implement the text summary generator (peak, trough, total, change, with units) and the "View as table" alternative rendered next to each chart; the figure has `role="img"` and `aria-labelledby`/`aria-describedby`.
6. Implement LTTB downsampling with documented parameters and the max-points constraint; ensure determinism.
7. Implement optional tooltip/crosshair data attributes consumed by the tooltip island.
8. Add golden SVG snapshot tests with tolerance and property tests (no NaN, bounded coordinates).
**Deliverables.**
- `crates/hdd-ui/src/charts/*`, golden files, docs, ADR
**Acceptance.**
- A1: the same input always yields byte-identical SVG.
- A2: every chart renders a correct empty state and a single-point state.
- A3: summaries are correct on 30 reference datasets (golden).
- A4: charts pass axe and contrast checks in both themes.
- A5: rendering 2,000 points completes within 5 ms p95 on the builder (criterion).
**Tests.**
- Unit/golden tests; proptest for arbitrary finite and non-finite inputs; criterion benchmark.
- Browser: print and forced-colors rendering.
**Notes.** NaN or infinite values are treated as gaps and reported in the data table alternative as "No data".
