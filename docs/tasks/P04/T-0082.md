### T-0082 · Internationalization runtime (Fluent), key checks and pseudo-locale
`P04` `[UI]` · deps: T-0023, T-0073 · size: L · owner: ui
**Objective.** Make every string translatable and verified.
**Steps.**
1. Vet the i18n library (Fluent bundles for Rust); write the ADR covering fallback chains, performance, and plural/gender support.
2. Implement the loader reading `i18n/<locale>/*.ftl` at build time into the binary (compile-time embedding), with runtime fallback to `en`.
3. Implement the `t!` macro/function with compile-time key existence checking and typed argument checking where feasible; missing keys at runtime render the key with a marker and increment a metric.
4. Implement locale negotiation (account, cookie, `Accept-Language`, default) and set `lang`/`dir`.
5. Implement `xtask i18n check`: missing keys per locale, unused keys, placeholder mismatches, forbidden concatenation patterns, long strings over limits, keys not matching the naming convention.
6. Implement the pseudo-locale generator (accented characters, +40% length, bracket markers) and a harness mode that renders pages in pseudo-locale and detects overflow/clipping.
7. Seed `i18n/en/*.ftl` from the copy deck B13 and prototype copy, organized by area (`common`, `auth`, `app`, `admin`, `public`, `errors`, `email`).
8. Document the translator workflow and context notes format.
**Deliverables.**
- `crates/hdd-web/src/i18n/*`, `i18n/en/*.ftl`, `xtask i18n`, pseudo-locale generator, ADR
**Acceptance.**
- A1: a missing key fails the build or test in CI (compile-time or check).
- A2: pseudo-locale rendering of the gallery shows no clipped text (automated check using scroll width vs client width).
- A3: placeholder mismatches between locales are detected.
- A4: `lang` and `dir` attributes are correct per locale.
- A5: concatenated sentences are rejected by lint.
**Tests.**
- Unit: negotiation table tests; Fluent plural tests (English, plus a synthetic few/many locale); proptest for argument formatting never panicking.
- Browser: pseudo-locale overflow test across the gallery.
**Notes.** Additional locales are added by dropping `.ftl` files; the operator decides which ship.
