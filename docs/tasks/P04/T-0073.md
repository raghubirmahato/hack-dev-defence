### T-0073 · `hdd-web` skeleton: surfaces, host routing, configuration and graceful lifecycle
`P04` `[UI][API]` · deps: T-0014, T-0072 · size: L · owner: ui
**Objective.** Create the server that renders all three surfaces by Host with production-grade lifecycle behavior.
**Steps.**
1. Create the `axum` application in `hdd-web` with typed configuration (`figment`) from the variables of B10 (`HDD_WEB_BIND`, `HDD_PLATFORM_DOMAIN`, surface hosts), failing loudly on invalid or missing values.
2. Implement host-based surface routing: `public`, `app`, `admin` routers mounted per `Host`; unknown hosts get a neutral 404; the `admin` surface checks `HDD_ADMIN_CIDRS` at the router layer before any handler (generic `ERR-AUTH-015`). Cookie-authenticated JSON calls use the same-origin `/api/v1/*` mount of the `app` and `admin` hosts (B2.1), forwarded to `hdd-api`; `hdd-web` itself never accepts bearer keys.
3. Implement the route table from `docs/UX/routes.toml`: each route declares screen ID, surface, permission ID, method set and rate-limit class; `xtask routes check` fails if code and TOML disagree and if any handler lacks a permission declaration.
4. Implement middleware layers: request ID (ULID/UUIDv7), tracing with JSON logs and redaction, panic catching at task boundary incrementing `MET-hdd_panics_total`, body size limits, timeout, compression (negotiated), security headers (T-0075), and metrics (`MET-hdd_web_requests_total`).
5. Implement graceful shutdown (drain in-flight within a configured window) and readiness (`/readyz` depends on database/Redis checks once present; before that reports `degraded` honestly).
6. Implement `/healthz`, `/readyz`, `/metrics` on the private listener only.
7. Implement the placeholder-free authorization hook: until identity exists (P06), non-public routes respond with `503 ERR-SYS-001` unless the request originates from loopback and the route is explicitly marked `dev_gallery` (only the design-system gallery), and this hook is replaced by real session authz in T-0125.
8. Document the lifecycle and configuration in `OPERATIONS.md`.
**Deliverables.**
- `crates/hdd-web/src/{main,config,router,surfaces,middleware}/*`, `xtask routes check`, docs
**Acceptance.**
- A1: requests with an unknown Host return a neutral 404 with no tenant or platform detail.
- A2: the admin router rejects non-allowlisted peers before routing (test with a fake peer address through a test listener).
- A3: `xtask routes check` fails when a handler is added without a permission declaration.
- A4: SIGTERM drains within the configured window and exits 0 (integration test).
- A5: panics in handlers return a generic 500 and increment the panic metric.
**Tests.**
- Unit tests for host parsing and surface selection; integration tests using real sockets.
- Property test: arbitrary `Host` header strings never panic and never select the wrong surface.
**Notes.** `dev_gallery` exposure is temporary and explicitly tracked in STATUS as removed by T-0125.

## Definition of done for this task's tags (section 0.7)

### `[UI]`: Renders HTML to a human

Server-side escaped output only; empty, loading, error, offline and permission-denied states implemented honestly (no fake data); keyboard-only operation verified; focus order and visible focus; WCAG 2.2 AA via the axe oracle with zero serious or critical findings; contrast tokens only (no ad-hoc colors); responsive screenshots at 360, 768, 1280 px in dark and light; i18n keys only (no literal user-facing strings in templates); CSP clean (no inline script or style, no console errors); size budgets (E4) respected; visual-regression baseline updated with reviewer note.

### `[API]`: Adds or changes an HTTP endpoint

OpenAPI entry via `utoipa`; RFC 9457 problem responses using the error catalog; authz check by permission ID (deny by default); tenant scoping test (BOLA); input validation with explicit limits; idempotency key on create; `ETag`/`If-Match` on update; rate limit class assigned; audit event; metric; contract test generated from the OpenAPI document.
