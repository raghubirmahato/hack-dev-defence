### T-0205 · TLS control-plane test suite
`P10` `[QA]` · deps: T-0199, T-0200, T-0201, T-0202, T-0203, T-0204 · size: L · owner: qa
**Objective.** Verify the whole TLS management layer without depending on the live CA.
**Steps.**
1. Stand up a local ACME server compatible with RFC 8555 (a real implementation, started in tests) with configurable failure injection (rate limits, invalid challenges, delays).
2. Test end-to-end flows: HTTP-01 planning (token publication), DNS-01 flows, renewal, duplicate prevention, budget enforcement, rate-limit retry, failure backoff.
3. Test custom certificate upload with 60 generated certificates (valid and invalid) and fuzzed inputs.
4. Test HSTS ramp, redirect policy and settings revisions end to end through the API and UI.
5. Test CT monitor logic and expiry alerting with the clock.
6. Test origin pin management with local TLS servers.
7. Test RLS and BOLA for all new endpoints.
8. Record durations and flake rates; fix flakes at the root cause.
**Deliverables.**
- `tests/tls/*`, local ACME harness, reports
**Acceptance.**
- A1: all flows pass deterministically in 5 consecutive runs.
- A2: failure injection scenarios behave per specification.
- A3: BOLA suite covers all new routes.
- A4: no secret material appears in test logs (scanner).
- A5: suite runtime is under 10 minutes.
**Tests.**
- The suite itself and the log scanner.
**Notes.** Live ACME staging tests run in P11 (AC-04).
