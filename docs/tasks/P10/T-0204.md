### T-0204 · Wildcard and preview-zone certificate flows
`P10` `[API][UI][OPS]` · deps: T-0198, T-0166 · size: M · owner: dns
**Objective.** Support DNS-01 wildcard issuance and the platform's preview hostname certificate.
**Steps.**
1. Implement wildcard requests for `full_ns` zones (DNS-01 via HDD's own DNS API: write TXT records `_acme-challenge` with short TTL, verify availability via the answer engine and live queries before notifying the CA, clean up after validation).
2. Implement wildcard via CNAME delegation for partial modes (the owner's `_acme-challenge` CNAME points to `<zone-id>.acme.{{PLATFORM_DOMAIN}}`, where HDD controls TXT records); implement the acme helper zone data model and answer rules in the DNS engine (system zone).
3. Implement the platform preview wildcard certificate (`*.preview.{{PLATFORM_DOMAIN}}`) and edge wildcard as platform-managed certificates with ownership by the platform org.
4. Implement concurrency control (one DNS-01 challenge per name at a time, TXT set accumulates multiple values for wildcard + apex).
5. Implement failure handling (propagation delay waits with probes, partial cleanup, orphan TXT removal job).
6. Implement UI states in S-051 for wildcard flows with clear explanations.
7. Add tests with the local ACME server and a real local DNS server serving the TXT records.
8. Document security implications of delegating `_acme-challenge` (CNAME only for that label).
**Deliverables.**
- DNS-01 module, helper zone logic, UI states, tests
**Acceptance.**
- A1: TXT challenge records are removed after validation and orphans are cleaned.
- A2: wildcard issuance succeeds against the local ACME server end to end.
- A3: CNAME-delegated issuance works for a partial-mode domain in tests.
- A4: only `_acme-challenge` labels are writable via the helper zone mechanism (authorization test).
- A5: platform wildcard certificates are not accessible to tenants.
**Tests.**
- Integration (local ACME + DNS); unit: TXT set management; security: attempt to write other labels.
**Notes.** Live issuance on staging occurs in T-0218.
