### T-0246 · Scoring engine, thresholds and `docs/SCORING.md`
`P13` `[DP][DOC]` · deps: T-0245 · size: M · owner: waf
**Objective.** Decide blocks consistently from hard and soft matches.
**Steps.**
1. Implement severity weights (Critical 5, Error 4, Warning 3, Notice 2), per-category caps (so a single noisy category cannot dominate: default cap 15), and the anomaly score aggregation with deterministic ordering.
2. Implement the decision logic: any **hard** match above the active paranoia level yields `Block` regardless of score; otherwise block when `score >= block_threshold`; paranoia level gates which rules are active (rule `paranoia` ≤ site level); thresholds are per site (default 5) and separate from paranoia.
3. Implement mode handling in the engine output: the engine always computes the full verdict; the **mode** (off/monitor/log/block) is applied by the caller (proxy/dry-run) so `would_block` is always available.
4. Implement per-vector scoring multipliers where defined (for example headers lower weight for generic keywords) documented in rule metadata.
5. Implement score explanation output (list of contributing matches with weights) for the event drawer and dry-run.
6. Write `docs/SCORING.md` precisely (formulas, examples, edge cases, interplay with exceptions and presets).
7. Test with 100 scenario tables (combinations of matches yielding expected decisions), plus property tests (adding a match never decreases the score; hard match always blocks).
8. Benchmark scoring overhead (under 5 µs per request).
**Deliverables.**
- scoring module, docs, tests
**Acceptance.**
- A1: the formulas in `docs/SCORING.md` are executable examples verified by doc-tests.
- A2: hard matches at inactive paranoia levels do not block (explicit tests).
- A3: category caps behave as specified.
- A4: explanations list all contributing matches deterministically.
- A5: scoring overhead meets the benchmark.
**Tests.**
- Table (100) / proptest / doc-tests.
**Notes.** Presets set paranoia and threshold; they do not change rule weights.
