### T-0257 · Over-limit policy implementation
`P13` `[DP][SEC]` · deps: T-0240, T-0256 · size: M · owner: waf
**Objective.** Handle bodies and fields beyond inspection limits explicitly and visibly.
**Steps.**
1. Implement `inspect_prefix` (default): inspect the first N bytes (`inspect_body_max_bytes`, default 128 KiB), tag the verdict `truncated=true`, and record the metric; for streaming bodies the proxy passes the buffered prefix to the engine while continuing to stream the rest after the decision.
2. Implement `block`: requests whose body exceeds the limit (or Content-Length declares more) are blocked with 413 or 403 (configurable) and an event of category `proto`/`upload` subtype `over_limit`.
3. Implement `pass`: no further inspection beyond the prefix; the metric and UI warning make this visible; document risk (attackers can pad payloads beyond the limit; ATK-013 padding variant).
4. Implement the **padding attack mitigation** under `inspect_prefix`: additionally scan the **tail window** (last 16 KiB) of bodies up to a cap (buffered tail for requests below 10 MiB) and sample middle windows for JSON/form bodies where structure allows field-wise inspection (fields beyond the prefix are inspected individually up to the field cap), so adding junk at the start does not hide payloads in later fields.
5. Implement per-field caps and chunked windows (T-0240) for long single values.
6. Implement metrics (`MET-hdd_waf_truncated_total{policy}`) and event tags.
7. Implement tests: payload after 1 MiB of padding in JSON/form/multipart under each policy; boundary conditions at exactly N bytes.
8. Document the residual risk in `SECURITY.md` and S-055 copy.
**Deliverables.**
- policy implementation, tests, docs
**Acceptance.**
- A1: under `inspect_prefix`, a payload placed in a late JSON field is still detected (field-wise inspection) up to the field cap.
- A2: under `block`, oversize bodies are blocked with the documented status and event.
- A3: under `pass`, the UI warns and metrics increment.
- A4: boundary tests at N-1, N, N+1 behave consistently.
- A5: tail-window scanning detects payloads appended after padding for non-structured bodies.
**Tests.**
- Table/proptest on positions; integration through the proxy harness.
**Notes.** Residual risk is a documented known limitation (C9.5).
