### T-0002 · Create the state files and the deviation log
`P00` `[DOC]` · deps: T-0001 · size: S · owner: docs
**Objective.** Give every future session the same three entry points and a place to record deviations, so no knowledge lives in chat.
**Steps.**
1. Write `AGENTS.md` (at most 150 lines): non-negotiable rules digest (R-01 to R-30 one line each), the commands (`cargo xtask verify`, `ui verify`, `acceptance`), current phase and task pointer, where things live, the session start ritual of section 0.1, and the stop conditions (STOP #1, STOP #2, approvals).
2. Write `STATUS.md` with sections: Current phase and milestone; Task table (ID, title, state, evidence link, commit); Open risks; Open questions (seeded from Appendix E8); UNVERIFIED list (ID, reason code, what the operator must supply); Last gate report summary.
3. Write `HANDOFF.md` with the template: phase, failing tests, next 10 tasks, decisions made, open questions, commands to resume.
4. Create `docs/DEVIATIONS.md` with the table header (ID, deviation, reason, date, approver) and pre-seed `DEV-V5-000` to `DEV-V5-003` (`DEV-V5-000` splitter script; `DEV-V5-001` Vuln-Lab exception to "no dummy origin"; `DEV-V5-002` rust-share definition; `DEV-V5-003` mandated SQLi set discrepancy) with the reasons from sections 0.1, 2.8, 5 and C4.1; `DEV-V5-004` (YAML to TOML fallback) and `DEV-V5-005` (UI stack choice) are added only if T-0006 or T-0071 trigger them.
5. Create `docs/diagnoses/` with a template file (symptom, evidence, hypotheses tried, options) and `docs/adr/0000-template.md`.
6. Add `.gitignore` entries: `hdd.live.yaml`, `secrets/`, `*.pem`, `.env`, `acceptance-*/`, `target/`, `*.log`, `.sqlx/` is **not** ignored (it is committed).
7. Link all state files from `README.md`.
8. Run a manual review: simulate a new session and confirm the files alone answer "what is next".
**Deliverables.**
- `AGENTS.md`, `STATUS.md`, `HANDOFF.md`
- `docs/DEVIATIONS.md`, `docs/diagnoses/TEMPLATE.md`, `docs/adr/0000-template.md`
- `.gitignore`
**Acceptance.**
- A1: `wc -l AGENTS.md` is at most 150.
- A2: `STATUS.md` lists all 599 tasks as `todo` except T-0001 and T-0002.
- A3: `DEVIATIONS.md` contains the four seeded entries with dates.
- A4: `git check-ignore hdd.live.yaml acceptance-x/foo` confirms the ignore rules.
- A5: a reviewer can find the next task and the stop conditions from `AGENTS.md` alone.
**Tests.**
- `cargo xtask verify` later enforces the 150-line limit and the presence of required sections.
- Manual dry read recorded in the commit body.
**Notes.** `AGENTS.md` is a digest, not a copy: it points to `docs/SPEC.md` and the split files for detail.
