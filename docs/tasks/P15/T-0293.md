### T-0293 · SSRF-in-parameters detector
`P15` `[DP][SEC]` · deps: T-0251 · size: L · owner: waf
**Objective.** Block attempts to make the origin fetch internal or metadata URLs.
**Steps.**
1. Implement URL extraction from parameters (full URLs, protocol-relative, bare hostnames/IPs in fields typed `url`, `uri`, `link`, `image`, `callback`, `webhook`, `feed`, `proxy`, `fetch`, `dest`, `target`, `endpoint`), JSON fields, headers (`X-Forwarded-Host`, `X-Original-URL`, `Referer` is not treated as SSRF).
2. Implement host classification via a WHATWG-like URL parser with alternative IP representations: decimal (`2130706433`), hex (`0x7f000001`), octal (`0177.0.0.1`), dotted-mixed, IPv6 (`[::1]`, `[::ffff:127.0.0.1]`), zero-compression forms, `0.0.0.0`, `localhost` and subdomains, DNS-rebinding services (`nip.io`, `sslip.io`, `xip.io`, `lvh.me`, `localtest.me`, `*.localhost`), userinfo tricks (`http://good.example@127.0.0.1/`), fragments/backslash confusion, and unicode dots.
3. Classify targets: loopback, private (RFC 1918, CGNAT), link-local (including `169.254.169.254`, `fd00:ec2::254`), metadata hostnames (`metadata.google.internal`, `metadata.azure.com`? use `169.254.169.254` and named hosts list, `100.100.100.200`), cloud-internal suffixes (`.internal`, `.local`, `.svc`, `.cluster.local`), unspecified, multicast.
4. Detect dangerous schemes: `gopher`, `dict`, `ftp`, `file`, `ldap(s)`, `jar`, `netdoc`, `tftp`, `sftp`, `smb`, `php`, `data` in URL-typed fields.
5. Detect OAST/callback domains (`oast.*`, `interact.sh`, `burpcollaborator.net`, `canarytokens.com`, `requestbin`, `webhook.site`, `pipedream`, `.invalid` fixtures) as soft 3 (benign usage exists) rising to hard when combined with internal targets or in fields not expected to be URLs.
6. Hardness: internal/metadata/scheme-abuse targets are hard in URL-typed fields and soft 4 elsewhere; define subtypes (`loopback`, `private`, `metadata`, `scheme`, `encoded_ip`, `rebinding_name`, `oast`).
7. Fixtures for ATK-091 to ATK-097 (all textual) and counter-examples (legitimate external URLs, links in comments, `example.com` references).
8. Benign gate and fuzz on URL parsing.
**Deliverables.**
- URL canonicalizer, SSRF detector, rules, fixtures (≥ 150), tests
**Acceptance.**
- A1: all alternative IP encodings of loopback and metadata addresses are classified correctly (table of 80).
- A2: userinfo/fragment/backslash tricks are resolved to the true host before classification.
- A3: external legitimate URLs in URL-typed fields pass.
- A4: the shared URL classifier is the same code used by the egress SSRF guard tests (property test equivalence on the host classification subset).
- A5: zero false positives on benign corpora.
**Tests.**
- Table (200) / proptest on IP representations / fuzz URL parser.
**Notes.** ATK-091 to ATK-097; same classification table as T-0009 to avoid drift.
