### T-0288 · Path traversal, LFI and RFI
`P15` `[DP][SEC]` · deps: T-0262 · size: L · owner: waf
**Objective.** Block file-access and inclusion attacks across encodings and platforms.
**Steps.**
1. Implement path canonicalization for traversal detection: decode layers, normalize separators (`\` to `/`), collapse `./`, resolve `..` segments with underflow detection, handle overlong UTF-8 `..%c0%af`, `%2e%2e%2f`, `%252e%252e%252f`, `..;/`, `....//`, `.%2e/`, Unicode dots and slashes folded, trailing dots/spaces (Windows), 8.3 names, NTFS ADS (`::$DATA`), UNC `\\host\share`.
2. Detect traversal sequences in parameters and in path segments (distinguishing legitimate relative paths in specific fields via field kinds: `file`, `path`, `page`, `template`, `include`, `dir`, `doc`, `download` are high-risk).
3. Detect sensitive absolute targets: `/etc/passwd`, `/etc/shadow`, `/etc/hosts`, `/proc/self/environ`, `/proc/self/cmdline`, `/proc/version`, `/root/.ssh/`, `/var/log/`, Windows `c:\windows\win.ini`, `boot.ini`, `system32\config\sam`, `web.config`, `.htaccess`, `.htpasswd`, `wp-config.php`, `config.php`, `.env`, `id_rsa`.
4. Detect PHP wrappers and URL-in-include patterns: `php://filter`, `php://input`, `php://stdin`, `data://`, `expect://`, `phar://`, `zip://`, `compress.zlib://`, `file://`, `glob://`, `ssh2://`, and remote includes `http(s)://`/`ftp://` in include-style parameters (RFI).
5. Define subtypes (`traversal`, `sensitive_file`, `wrapper`, `rfi`) with hardness: traversal hard when depth ≥ 2 or targets sensitive files; single `../` in a generic path field soft 3; wrappers and sensitive files hard.
6. Fixtures for ATK-079 to ATK-090 (path and parameter forms), counter-examples (relative links in markdown fields, `../` in documentation prose, dot-containing filenames, URLs in `redirect` fields (handled elsewhere)).
7. Extend the same detector to **path vector** inspection with canonical path comparison (differential between decoded and server-normalized path to catch normalization bypasses `/..;/`, `//`).
8. Benign gate and benchmarks.
**Deliverables.**
- detector, rules, fixtures (≥ 200), tests
**Acceptance.**
- A1: encoded, double-encoded, overlong and backslash variants are detected.
- A2: Windows and Linux sensitive paths are detected.
- A3: wrappers and RFI patterns are hard.
- A4: legitimate relative paths in prose are not hard.
- A5: zero false positives on benign corpora.
**Tests.**
- Table (300) / proptest (path permutations) / fuzz.
**Notes.** Hosts in RFI fixtures use `.invalid`.
