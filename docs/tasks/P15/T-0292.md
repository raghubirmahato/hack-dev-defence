### T-0292 · XXE and XML attack detection
`P15` `[DP][SEC]` · deps: T-0249 · size: M · owner: waf
**Objective.** Detect XML external-entity and related attacks without ever resolving entities.
**Steps.**
1. Use the bounded XML tokenizer (T-0249) to detect `<!DOCTYPE` with internal subsets, `<!ENTITY` declarations (general and parameter entities `%name;`), `SYSTEM` and `PUBLIC` identifiers with `file://`, `http(s)://`, `ftp://`, `expect://`, `php://`, `gopher://`, `jar:`, `netdoc:`; classify external vs internal entity declarations.
2. Detect XInclude (`xi:include`, `http://www.w3.org/2001/XInclude`), XSLT (`xsl:stylesheet`, `xsl:import`, `document(`, `xsl:value-of select="system-property"`), SVG with external references, SOAP envelope abuse, and XML in unexpected content types.
3. Detect entity-expansion DoS shapes by counting entity declarations and nested references (without expanding) and applying size heuristics (billion laughs, quadratic blowup): Class C descriptors only, never real bombs.
4. Hardness: any `DOCTYPE` with `ENTITY` declarations is hard on endpoints not declared to accept DTDs (default all); `DOCTYPE` without entities is soft 3 (some legitimate XHTML); XInclude and XSLT constructs hard.
5. Inspect XML inside uploads and archives (DOCX/XLSX/PPTX/SVG) via archive peeking caps (T-0249), scanning `word/document.xml`, `[Content_Types].xml`, `xl/sharedStrings.xml` for DTD constructs.
6. Define subtypes (`xxe`, `xxe_oob`, `xinclude`, `xslt`, `entity_expansion`) and ATK links (ATK-098 to ATK-101, ATK-060).
7. Fixtures: Class A/B inert XML payloads with `.invalid` hosts; counter-examples (legitimate XHTML doctype, SOAP).
8. Benign gate and fuzz on XML tokenizer.
**Deliverables.**
- detector, rules, fixtures (≥ 100), tests
**Acceptance.**
- A1: classic and parameter-entity XXE payloads are hard.
- A2: XHTML doctype without entities is not hard.
- A3: uploads of DOCX containing DTD constructs are flagged without full extraction.
- A4: expansion shapes are flagged by counting, not expanding (memory bound test).
- A5: zero false positives on benign corpora.
**Tests.**
- Table (120) / fuzz / memory bound tests.
**Notes.** The origin parser is not our concern; we block the shapes.
