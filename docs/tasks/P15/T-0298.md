### T-0298 · HTTP method policy and request-semantics anomalies
`P15` `[DP][SEC]` · deps: T-0262 · size: M · owner: waf
**Objective.** Constrain unusual methods and header-based semantics tampering.
**Steps.**
1. Implement method policy: allow `GET`, `HEAD`, `POST`, `PUT`, `PATCH`, `DELETE`, `OPTIONS` by default; block `TRACE`, `TRACK`, `CONNECT` (protocol-level), `DEBUG`, and unusual WebDAV methods unless the site declares WebDAV; per-path method allowlists configurable (V8).
2. Detect method override headers (`X-HTTP-Method-Override`, `X-HTTP-Method`, `X-Method-Override`, `_method` parameter) and apply policy: ignore-with-log or block when attempting to turn `GET`/`POST` into `DELETE`/`PUT` unless declared.
3. Detect semantic-tampering headers: `X-Original-URL`, `X-Rewrite-URL`, `X-Forwarded-Path`, `X-Custom-IP-Authorization`, `X-Forwarded-For` with internal values when the peer is untrusted (informational because we strip), `X-Host`, `Forwarded` abuse; these are stripped/blocked per C9.3 and counted.
4. Enforce content-type policy: methods with bodies must declare `Content-Type` for declared API endpoints; reject `multipart/form-data` on JSON-only API paths (V8), and reject unusual combos (JSON with `Content-Length: 0`).
5. Detect unusual request-line shapes at the WAF layer that survived the protocol layer: very long paths (policy cap 8 KiB), repeated slashes patterns, `..;` segments, encoded NULs, non-printable characters.
6. Define categories (`method`, `proto`) and ATK links (ATK-150, ATK-151, ATK-057).
7. Fixtures: GET-safe shapes; counter-examples (OPTIONS for CORS preflight, legitimate `PUT` APIs).
8. Benign gate.
**Deliverables.**
- rules, config options, tests
**Acceptance.**
- A1: `TRACE` is blocked by default; CORS preflight `OPTIONS` passes.
- A2: method override headers are handled per policy.
- A3: per-path method allowlists work and are enforced.
- A4: stripped headers are counted and never forwarded.
- A5: zero false positives on benign corpora.
**Tests.**
- Table / integration with proxy harness.
**Notes.** Protocol-level rejections are P18.
