### T-0286 · XSS: encoding evasion, polyglots, mutation vectors and DOM hints
`P15` `[DP][SEC]` · deps: T-0285 · size: L · owner: waf
**Objective.** Close the common XSS filter bypasses.
**Steps.**
1. Handle encodings: HTML entities with and without semicolons, numeric entities in attribute values (`&#106;avascript:`), URL-encoded scheme splits (`java%0ascript:`, tabs/newlines inside scheme), Unicode escapes in JS (`\u0061lert`), `String.fromCharCode`, `atob`, `eval(unescape(...))`, `constructor.constructor` chains, backtick calls (`alert\`1\``), JSFuck-like symbol soups (high ratio of `[]()!+` characters) as soft signals escalating with length.
2. Handle structural tricks: slashes instead of spaces (`<img/src=x/onerror=...>`), null bytes, comments inside tags, attribute duplication, malformed closing, `<noscript>`/`<style>`/`<title>` mutation shapes, `<svg><script>` namespace switching, `<math><mtext><table>` mutation sequences, `<![CDATA[`, template elements.
3. Implement the polyglot detector: strings whose tokenization in multiple contexts (HTML text, attribute, JS string, URL) each yields executable constructs; hard.
4. Implement DOM-hint signals for fragment/query payloads (`#<img src=x onerror=...>`, `location.hash` consumers cannot be known, so keep soft 3) and `window.name` setters.
5. Implement CSS injection signals (`@import`, `expression(`, `behavior:`, `url(javascript:`).
6. Write fixtures for ATK-067 to ATK-070 and ATK-074 (AngularJS/Vue expression `{{constructor.constructor('alert(1)')()}}`) and rule metadata.
7. Define the evasion permutation generator for XSS (shared with proptest) and verify stability under three re-encodings.
8. Validate against benign corpora; document soft-only constructs.
**Deliverables.**
- rules, detector extensions, fixtures (≥ 150), tests
**Acceptance.**
- A1: scheme splitting by whitespace/entities/encoding is detected.
- A2: mutation and polyglot fixtures are hard (or documented soft with scores).
- A3: JSFuck-like inputs score proportionally but short symbol runs in normal text do not.
- A4: AngularJS/Vue expression payloads are hard on sites flagged as client-templated; soft otherwise.
- A5: zero false positives on benign corpora.
**Tests.**
- Table (250) / proptest transformations / fuzz.
**Notes.** The client-templated site option appears in S-055 (framework hints).
