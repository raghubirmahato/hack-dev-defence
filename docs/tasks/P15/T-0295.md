### T-0295 · Open redirect detection and redirect allowlists
`P15` `[DP][SEC][UI]` · deps: T-0293 · size: M · owner: waf
**Objective.** Prevent phishing redirects through the site's own redirector parameters.
**Steps.**
1. Detect redirect-style parameters (`next`, `url`, `redirect`, `redirect_uri`, `return`, `returnTo`, `return_url`, `continue`, `dest`, `destination`, `goto`, `target`, `callback`, `forward`, `out`, `link`, `to`) whose values resolve to a host different from the site's hostnames (using the URL canonicalizer from T-0293), including protocol-relative `//evil.invalid`, backslash `/\evil.invalid`, `https:evil`, userinfo `@` tricks, encoded variants, `javascript:`/`data:` schemes (hard).
2. Implement policy modes per site: `off`, `log`, `challenge` (redirect to challenge page then allow), `block`; default `log` (open redirects have legitimate uses such as SSO), with `javascript:`/`data:` always hard.
3. Implement the **redirect allowlist** (`allowed_redirect_hosts`) per site (S-056 settings): hosts permitted as redirect targets (exact and wildcard subdomain), with validation preventing overly broad entries.
4. Implement the optional **response-based** check: when the origin responds with 3xx and a `Location` header whose host differs from the site hosts and the request had a matching redirect parameter value, flag `open_redirect_confirmed` (critical in `monitor`, block in outbound block mode).
5. Define subtypes (`open_redirect`, `redirect_scheme`) and ATK links (ATK-102, ATK-103, ATK-075, ATK-284).
6. Fixtures: Class A GET shapes with `.invalid` hosts; counter-examples (same-site relative redirects, allowlisted SSO hosts).
7. Add UI for allowlist and mode in S-056 (category settings) and docs.
8. Benign gate.
**Deliverables.**
- detector, allowlist model, UI wiring, tests
**Acceptance.**
- A1: external-host redirects in redirect-style parameters are logged (default) or blocked by policy.
- A2: `javascript:` redirect values are always hard.
- A3: allowlisted hosts pass.
- A4: response-based confirmation works for 3xx responses.
- A5: relative paths never match.
**Tests.**
- Table (120) / integration with proxy harness / browser (allowlist UI).
**Notes.** Defaults avoid breaking SSO flows.
