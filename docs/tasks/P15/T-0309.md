### T-0309 · Sensitive-file honeypots, decoys and the tarpit option
`P15` `[DP][SEC]` · deps: T-0233, T-0308 · size: M · owner: waf
**Objective.** Implement tripwires that expose recon traffic with minimal risk to real users.
**Steps.**
1. Implement honeypot matching in the pipeline before the origin: exact and prefix paths (case-insensitive, trailing-slash tolerant, encoded variants), query-aware for files like `/.env?x=1`, and hidden-form-field honeypots (field name configured by the owner; any non-empty value in a form post is a hit).
2. Implement responses: `404` identical to normal not-found by default; optional realistic-looking decoy for common files (`/robots.txt` entries pointing to decoy paths?) only as inert text such as an empty `.env` or a fake `wp-login` page is not generated; the tarpit mode (off by default) delays the response by a bounded random 1 to 5 s with concurrency caps per client and globally.
3. Implement hit handling via the ban policy (cross-site context rule applies: hits from cross-site subresource requests do not ban); hits are `BB` for the default list, `S` (soft 3) for custom honeypots marked "monitor only".
4. Generate decoy `robots.txt` hints optionally: owner may add `Disallow: /admin-backup/` lines that point at honeypot paths (the product proposes, the origin must publish it; HDD does not modify origin responses by default).
5. Implement analytics: hits per path, unique IPs, top ASNs, time series, with links to bans.
6. Ensure honeypots never collide with real routes: compare against observed 2xx paths in the traffic sample (T-0233 check) and refuse activation when conflicts exist.
7. Link ATK-205, ATK-087, ATK-088, ATK-263 to ATK-266.
8. Tests with scripted scanners and real-browser cross-site image-tag poisoning attempts (expect no ban).
**Deliverables.**
- honeypot engine, tarpit, analytics, tests
**Acceptance.**
- A1: direct requests to default honeypots ban in block mode; cross-site subresource requests only block.
- A2: tarpit respects caps and is off by default.
- A3: honeypot conflicts with real routes prevent activation.
- A4: hidden-field honeypots catch filled fields without affecting normal posts.
- A5: analytics show accurate counts.
**Tests.**
- Integration with the proxy harness; browser poisoning test (AC-34 precursor); unit: matcher variants.
**Notes.** Matches V9 of the shield.
