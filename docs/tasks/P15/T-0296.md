### T-0296 · Deserialization signatures
`P15` `[DP][SEC]` · deps: T-0262 · size: M · owner: waf
**Objective.** Block serialized-object payloads for common runtimes.
**Steps.**
1. Implement format detectors on parameters, cookies, headers and bodies after base64/URL decoding attempts (bounded: up to two decode layers when the string looks like base64): Java (`aced0005`, `rO0AB`, `H4sIAAAAAAAA` gzip+base64 of Java streams), PHP (`O:\d+:"`, `a:\d+:{`, `s:\d+:"`, `C:\d+:"`, phar metadata signatures), Python pickle (protocol opcodes, `gASV`, `cos\nsystem`, `c__builtin__`, `!!python/object`), .NET (BinaryFormatter `AAEAAAD/////`, ViewState `/wEP`, `TypeNameHandling` `$type`), Ruby (`\x04\x08` Marshal header, `!ruby/object`), Node (`_$$ND_FUNC$$_`), YAML (`!!` tags), Jackson/Fastjson polymorphism (`@type`, `autoType`, `["java.lang.`, `com.sun.rowset.JdbcRowSetImpl`, `ldap://` within JSON).
2. Add gadget-name indicators (`ysoserial` common gadget class names: `CommonsCollections`, `Transformer`, `InvokerTransformer`, `TemplatesImpl`, `JdbcRowSetImpl`, `BadAttributeValueExpException`, `Spring`, `Groovy`) as hard when seen decoded.
3. Hardness: hard for magic bytes in places where binary serialization is not expected (cookies, query, form fields typed unknown), soft for protocols declared by the owner (an app legitimately using ViewState with MAC: ViewState structure detection is soft unless it fails typical shapes or includes gadget names).
4. Implement detection of padding/oracle probing patterns (repeated ViewState mutations) as repetition soft signals.
5. Define subtypes (`java_serialized`, `php_object`, `pickle`, `dotnet`, `ruby_marshal`, `node_serialize`, `yaml_tag`, `json_polymorphic`) and ATK links (ATK-105 to ATK-111).
6. Fixtures (inert strings, Class A for GET-safe shapes like `O:8:"stdClass":0:{}`), counter-examples (legitimate base64 images, JWTs, long tokens, ASP.NET ViewState with MAC on declared sites).
7. Benign gate and fuzz on decode attempts (bounded).
8. Document owner options for apps that legitimately use serialization.
**Deliverables.**
- detector, rules, fixtures (≥ 100), tests
**Acceptance.**
- A1: serialized object magic in cookies and parameters is hard.
- A2: JWTs and image base64 are not flagged.
- A3: gadget names are hard when decoded.
- A4: declared legitimate ViewState sites get soft handling only.
- A5: zero false positives on benign corpora.
**Tests.**
- Table (150) / fuzz / benign gate.
**Notes.** Bounded decoding prevents decode-bomb issues.
