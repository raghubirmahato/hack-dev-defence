### T-0290 · Code injection and server-side template injection
`P15` `[DP][SEC]` · deps: T-0242 · size: L · owner: waf
**Objective.** Detect dynamic-code and template-engine injection across popular stacks.
**Steps.**
1. Implement language-specific code injection signatures: PHP (`eval(`, `assert(`, `system(`, `exec(`, `passthru(`, `shell_exec(`, `popen(`, `proc_open(`, `create_function(`, `preg_replace` with `/e`, `include`/`require` of user input, backticks, `base64_decode(` chains, `<?php`, `<?=`), Python (`__import__`, `os.system`, `subprocess`, `eval(`, `exec(`, `compile(`, `pickle`), Node (`child_process`, `require('`, `process.mainModule`, `Function(`), Ruby (`system(`, `Kernel.`, backticks, `eval`, `IO.popen`), Java (`Runtime.getRuntime().exec`, `ProcessBuilder`, `ScriptEngine`), .NET (`Process.Start`, `System.Diagnostics`).
2. Implement SSTI detectors for Jinja2/Twig (`{{ ... }}` with arithmetic probes `{{7*7}}`, `{{config}}`, `{{self}}`, `__class__`, `__mro__`, `__subclasses__`, `__globals__`, `lipsum`, `cycler`, `joiner`, `namespace`, `|attr(`), Freemarker (`<#assign`, `${"freemarker.template.utility.Execute"?new()}`), Velocity (`#set($x=...)`, `$class.inspect`), Thymeleaf (`__${...}__::.x`, `th:`), ERB (`<%= ... %>`), Smarty (`{php}`, `{system(`), Mako (`<%`, `${`), Handlebars/Pug/EJS (`{{#with`, `-var`, `<%-`), Spring/EL (`#{`, `${T(java.lang.Runtime)`).
3. Hardness: hard for arithmetic probes combined with template delimiters in contexts where the delimiter pair is complete (`{{7*7}}`), gadget names, execution functions; soft for lone delimiters (`{{name}}` in a mustache-using site is legitimate user content only if the owner declares templating fields: provide the `template_syntax` site setting).
4. Define subtypes (`php_code`, `eval`, `ssti_jinja`, `ssti_java`, `ssti_other`, `el`) with category `code_injection` and `ssti`.
5. Fixtures for ATK-034 to ATK-039, ATK-051 and counter-examples (docs about templating, handlebars in CMS fields with exceptions).
6. Handle encodings and splitting (`{{7*'7'}}`, `{%raw%}`, comment splitting where valid).
7. Benign gate, fuzz, benchmark.
8. Document the `template_syntax` option.
**Deliverables.**
- rules, detectors, fixtures (≥ 200), tests
**Acceptance.**
- A1: `{{7*7}}`, `{{config.__class__.__mro__}}`, `<%= 7*7 %>`, `${T(java.lang.Runtime)...}` shapes are hard.
- A2: eval/system chains in PHP and Python are hard.
- A3: mustache-using sites with declared template syntax get scoped relaxations only for declared fields.
- A4: legitimate text in curly braces (JSON-like prose) is not hard.
- A5: zero false positives on benign corpora.
**Tests.**
- Table (250) / proptest / fuzz.
**Notes.** SSTI and expression-language families overlap with T-0291.
