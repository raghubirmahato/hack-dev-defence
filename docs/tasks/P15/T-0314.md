### T-0314 · Detector gate G15
`P15` `[QA][DOC]` · deps: T-0313 · size: M · owner: qa
**Objective.** Close phase P15.
**Steps.**
1. Run `xtask verify` with all detectors enabled, benign gates, fixture matrices (core and held-out), mutation tests for new modules, fuzz smoke, benchmarks.
2. Run the attack-matrix check and review the generated coverage document.
3. Run the oracle campaigns available in the lab (nikto, wapiti, nuclei, ZAP baseline against Vuln-Lab) in monitor mode if the lab exists; else `UNVERIFIED(capability_not_supplied)`.
4. Measure inspection latency with the full detector set under the functional profile and record p50/p99.
5. Review per-group held-out detection (≥ 95%) and diagnose gaps.
6. Compile the gate report with the matrix summary, rates, FP counts, mutation and coverage numbers.
7. Update the capability matrix (REQ-DET) and STATUS; carry over open ATK rows to their later owners.
8. Tag `gate-G15`.

- A1: every detected ATK row has fixtures, tests, rules and task mapping.
- A2: held-out detection ≥ 95% per group (or diagnoses recorded).
- A3: zero false positives on benign corpora; latency budgets hold.
