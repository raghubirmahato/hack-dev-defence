### T-0300 · Request-smuggling detection at the WAF layer
`P15` `[DP][SEC]` · deps: T-0299 · size: M · owner: waf
**Objective.** Add inspection-layer indicators that complement strict protocol parsing.
**Steps.**
1. Detect smuggling-shaped requests that parsers might accept: bodies containing a second HTTP request line (`GET /admin HTTP/1.1`, `POST / HTTP/1.1`) inside what was framed as a body, chunk extensions or trailers resembling headers, header names with whitespace or tabs before colon, `Transfer-Encoding` obfuscations (`Transfer-Encoding : chunked`, `Transfer-Encoding: xchunked`, `Transfer-Encoding:\tchunked`), duplicate `Content-Length` values, `Content-Length` with signs or hex, leading zeros.
2. Mark these as `smuggling` (hard in `R` mode: reject with 400 and close connection; ban on repeated/obvious attacks) with the protocol layer as the primary defense (T-0356) and the WAF layer as a second detection producing events.
3. Detect H2-specific smuggling inputs after downgrade: pseudo-header abuse (`:path` with spaces/CRLF), header names with uppercase, `transfer-encoding` presence in h2, `connection`/`keep-alive`/`upgrade` headers (forbidden in h2).
4. Detect cache-poisoning prerequisites: unkeyed header manipulation (`X-Forwarded-Host`, `X-Forwarded-Scheme`, `X-Forwarded-Proto` mismatches, `X-Original-URL`) already stripped but recorded.
5. Provide the differential test harness: send ambiguous requests to HDD and to a back-end test server and compare how each parses them; HDD must reject anything where interpretations differ.
6. Link ATK-135 to ATK-141, ATK-146, ATK-155.
7. Fixtures at the byte level (raw socket tests used in P18).
8. Metrics and events.
**Deliverables.**
- detection rules, differential harness, tests
**Acceptance.**
- A1: embedded request-line-in-body is flagged.
- A2: obfuscated TE headers are rejected.
- A3: differential harness finds zero parsing disagreements on the ambiguity corpus (HDD rejects them).
- A4: events are emitted with subtype and the connection is closed.
- A5: legitimate chunked requests pass.
**Tests.**
- Raw-socket table tests; differential tests; fuzz of the HTTP parser path.
**Notes.** Comprehensive raw-socket testing is AC-14 (T-0373).
