### T-0303 · BOLA/IDOR enumeration heuristics and mass-assignment signals
`P15` `[DP][SEC]` · deps: T-0302 · size: M · owner: waf
**Objective.** Flag object-level authorization probing that no signature can see.
**Steps.**
1. Identify object-ID path/query parameters (numeric IDs, UUIDs, slugs in positions flagged by schema or by learned patterns `/users/{id}`), track per (session/token/IP key, endpoint pattern) the distinct IDs requested in a window (HyperLogLog or bounded set), and flag sequential or high-cardinality enumeration (≥ 30 distinct IDs within 2 minutes with monotonic stepping or ≥ 100 distinct IDs within 10 minutes) as `bola_enumeration` (soft 3, escalating to challenge).
2. Track response patterns: many 403/404 interleaved with 200s on an ID-bearing endpoint strongly suggests enumeration; combine with the above.
3. Identify mass-assignment attempts: JSON/form fields not in the schema or in a sensitive-names list (`role`, `roles`, `isAdmin`, `is_admin`, `admin`, `permissions`, `scope`, `verified`, `balance`, `price`, `owner_id`, `user_id`, `tenant_id`) on create/update endpoints; log (`mass_assignment`) with low score, upgradable by owner config.
4. Provide per-site settings (thresholds, sensitive names, endpoints) and UI in S-056 under API protection.
5. Provide privacy-preserving storage: IDs are hashed per site with a rotating salt; counters expire in 15 minutes.
6. Emit events and attention items; do not ban on these signals alone (policy: challenge on enumeration; ban only when combined with hard hits).
7. Link ATK-173, ATK-174, ATK-175, ATK-049.
8. Test with scripted enumeration and legitimate pagination/prefetching traffic.
**Deliverables.**
- tracker, rules, UI wiring, tests
**Acceptance.**
- A1: sequential enumeration of 50 IDs is flagged; normal pagination of 30 items is not.
- A2: stored data contains only hashes with expiry.
- A3: sensitive-field submissions are logged with the field name only.
- A4: challenge action triggers per policy; no ban without other evidence.
- A5: false-positive rate on benign API traffic corpora is zero at default thresholds.
**Tests.**
- Simulation tests; privacy inspection; benign API traffic replay.
**Notes.** Tier 1 treats these as signals; blocking is opt-in.
