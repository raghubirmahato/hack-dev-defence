### T-0369 · Origin health checks, passive detection and serve-stale
`P18` `[DP][OPS]` · deps: T-0365 · size: M · owner: dp
**Objective.** Know when origins are down and degrade gracefully.
**Steps.**
1. Implement active health checks per origin: configurable path/method/expected status (default `GET /` expecting < 500 within 5 s, interval 10 s with jitter, minimum 1 per 10 s per origin to respect section 2.9), consecutive failure/success thresholds (3 failures to down, 2 successes to up), TLS verification identical to traffic.
2. Implement passive detection: track error rates and latency from real traffic (5xx, resets, timeouts) feeding the state machine, with fast failure when error rate exceeds 50% over 20 requests.
3. Implement states (healthy, degraded, down) with hysteresis, history persisted via `origin_health`, notifications (`origin down/recovered`), metrics (`MET-hdd_origin_health`), and attention items.
4. Implement serve-stale (opt-in): for cacheable GET responses (when a cache exists in P32) or for the branded error page; Tier 1: branded 502/504 with Retry-After and the owner's custom message; stale caching deferred but the hook defined.
5. Implement protection against health-check abuse: tenants cannot set intervals below 10 s; checks never follow redirects; checks use a user agent `HDD-HealthCheck`; bodies limited.
6. Implement a "force check" API with rate limits and UI integration (S-053).
7. Test with origins flapping, partially failing paths, TLS failures, slow start.
8. Document tuning.
**Deliverables.**
- health checker, state machine, tests
**Acceptance.**
- A1: an origin outage is detected within 30 s (3 failed checks at 10 s) and recovery within 20 s.
- A2: passive detection reacts within 20 requests to a failing origin.
- A3: checks respect the per-origin rate limit.
- A4: notifications fire once per state change (dedupe).
- A5: TLS failures are reported as such (not generic down).
**Tests.**
- Integration with flapping local origins; unit: state machine (proptest).
**Notes.** Multi-origin failover arrives in P32.
