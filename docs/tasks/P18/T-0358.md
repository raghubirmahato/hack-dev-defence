### T-0358 · h2-to-h1 downgrade safety and header normalization
`P18` `[DP][SEC]` · deps: T-0356, T-0357 · size: M · owner: dp
**Objective.** Prevent request smuggling when translating HTTP/2 requests to HTTP/1.1 upstream.
**Steps.**
1. Implement strict translation rules: derive `Host` from `:authority` (validated against the site), build the request line from validated `:method` and `:path` (reject spaces, CR/LF, NUL, fragments), and reject requests whose `:authority` and `Host` headers disagree.
2. Always compute framing for the upstream request from the actual body: set exactly one `Content-Length` (or use chunked for unknown length), never forward client `Content-Length`/`Transfer-Encoding` values unvalidated; reject h2 requests with `content-length` not matching the sum of DATA frames.
3. Reject or normalize header names/values that are valid in h2 but dangerous in h1 (CR/LF/NUL, leading/trailing whitespace, header names with special characters, extremely long values), and drop h2-only pseudo semantics.
4. Convert cookies: multiple `cookie` header fields in h2 are joined with `; ` per RFC 9113.
5. Prefer h2 or h1.1 upstream per origin capability negotiation (ALPN); when the origin supports h2, use h2 end to end with the same hardening; otherwise downgrade safely.
6. Test with a corpus of h2 smuggling vectors (H2.CL, H2.TE, CRLF in header values/names/pseudo-headers) against a back-end test server that would be vulnerable if bytes were forwarded verbatim.
7. Add differential tests that reconstruct the upstream bytes and verify equivalence with a canonical serializer.
8. Fuzz the translator.
**Deliverables.**
- translation layer, corpus, tests
**Acceptance.**
- A1: all H2.CL/H2.TE/CRLF vectors are rejected before any byte reaches the origin (origin socket capture shows zero bytes).
- A2: valid requests translate identically to a reference serializer (differential).
- A3: mismatched `:authority`/`Host` is rejected.
- A4: DATA length mismatches are rejected.
- A5: fuzzing is clean.
**Tests.**
- Raw h2 test client + capture origin; differential; fuzz.
**Notes.** ATK-138.
