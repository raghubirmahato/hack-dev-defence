### T-0370 · Safe mode: file flag, API and `hddctl`
`P18` `[DP][OPS][SEC]` · deps: T-0362 · size: M · owner: ops
**Objective.** Provide an instant, auditable pass-through switch for emergencies.
**Steps.**
1. Implement the safe-mode state sources: file flag (`HDD_SAFE_MODE_FLAG`, inotify/poll every 500 ms), platform state in Postgres (`platform_state.safe_mode` with expiry), and per-site safe mode (T-0235); the effective state is the OR of platform and site states.
2. Implement behavior: pass-through (no inspection, jail, rate limits, challenge, outbound filters) while TLS termination, routing, Ray ID, security headers and the secret origin header remain; event pipeline records a `safe_mode_active` marker per minute and counts requests passed; visitor pages are unaffected.
3. Implement `hddctl safe-mode on|off [--duration 30m] [--reason ...]` working with the API down (writes the flag file and, if reachable, Postgres), the platform API (`POST P/emergency/safe-mode`), and the admin UI (S-122) with typed confirmation and automatic expiry (default 60 min, max 24 h).
4. Implement visibility: banners in all app/admin surfaces, status page note (internal-only unless the operator chooses to publish), metrics `MET-hdd_safe_mode`, notifications to platform admins and tenant owners (configurable).
5. Implement safeguards: safe mode cannot be left on silently (expiry required; extended only explicitly), periodic reminders, and audit events with the reason.
6. Implement tests: switching under load (no dropped connections), flag file appears/disappears, API vs file precedence, expiry.
7. Include in AC-13 (same attack passes under safe mode with TLS/routing intact; blocks after off).
8. Document break-glass usage in the runbook.
**Deliverables.**
- safe mode implementation, CLI, tests, docs
**Acceptance.**
- A1: toggling safe mode takes effect in under 1 s from file change.
- A2: under safe mode the same attack request passes while TLS and Ray ID remain intact.
- A3: expiry returns to normal automatically.
- A4: audit and notifications are generated.
- A5: switching does not drop in-flight connections.
**Tests.**
- Integration under load; unit: state resolution.
**Notes.** Safe mode is the operator's emergency brake (R-26 exception, explicit and audited).
