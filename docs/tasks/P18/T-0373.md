### T-0373 · Raw-socket protocol test suite (AC-14) and oracle checks
`P18` `[QA][SEC]` · deps: T-0356, T-0357, T-0358, T-0367 · size: XL · owner: qa
**Objective.** Verify every protocol hardening claim with real bytes.
**Steps.**
1. Implement the `protocol-abuse` check set in `hdd-acceptance` using raw sockets, `h2` and `rustls`: conflicting CL/TE → 400; obs-fold, absolute-form, bare LF, space before colon, CRLF anomalies → rejected; oversized request line/header block/body → 414/431/413; Slowloris (header dribble) cut off; slow POST cut off; gzip/brotli/zstd bombs (descriptor-sized, capped) rejected; h2 Rapid Reset, CONTINUATION flood, HPACK bomb, SETTINGS/PING/empty-frame/priority floods contained; h2-to-h1 smuggling attempts rejected; `Expect` handling; chunk-extension abuse.
2. Enforce profile caps: 5 connections, 2,000 frames, 10 MiB per test, targeting only `sandbox_hostname` (live) or builder-local stacks, with the kill switch and TargetGuard.
3. Run `h2spec` as an oracle against the builder stack and compare with documented intentional deviations; run additional protocol conformance oracles available (e.g., `curl --http2`, `nghttp`) for sanity.
4. Verify after each test that the process is healthy: readiness OK, memory/CPU within bounds, no panics (`MET-hdd_panics_total` unchanged), subsequent normal requests succeed.
5. Cover WebSocket and gRPC passthrough checks (UNVERIFIED if the sandbox site has none).
6. Produce a matrix report mapping each ATK row (AG-08, AG-12 protocol items) to check IDs and results.
7. Record raw evidence (bytes sent/received hex dumps, truncated) with SHA-256.
8. Fix failures at root cause (R-14).
**Deliverables.**
- check implementations, reports
**Acceptance.**
- A1: every attack class results in the specified rejection and process health after.
- A2: reports map to ATK rows with PASS/FAIL.
- A3: `h2spec` deviations are only the documented intentional hardening ones.
- A4: caps are never exceeded by the generators (instrumented counters).
- A5: evidence with hashes exists.
**Tests.**
- The suite (builder-local and sandbox).
**Notes.** AC-14 is the protocol claim evidence for S-003.
