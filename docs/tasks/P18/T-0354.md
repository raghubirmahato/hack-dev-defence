### T-0354 · TLS termination: crypto provider ADR, SNI resolver, policy and refusal behavior
`P18` `[DP][SEC]` · deps: T-0353, T-0195 · size: L · owner: sec
**Objective.** Terminate TLS correctly, quickly and with strict defaults.
**Steps.**
1. Decide the `rustls` crypto provider (`ring` vs `aws-lc-rs`) in an ADR using measurements (handshake throughput, binary size, FIPS considerations, FFI implications recorded as `DEV` if `aws-lc-rs`), and set the build features accordingly.
2. Implement the custom `ResolvesServerCert`: lookup by SNI in the snapshot's certificate map (exact, then wildcard), choose between RSA/ECDSA certificates by client capabilities, return no certificate for unknown/absent SNI which results in an `unrecognized_name` alert or handshake failure (default); the optional default certificate exists only behind an explicit flag and never serves tenant content.
3. Configure protocol versions (TLS 1.2 and 1.3; 1.3-only per site), cipher suite order (provider defaults restricted to AEAD with forward secrecy), ALPN (`h2`, `http/1.1`), session tickets (key rotation every 12 h with overlap, derived from a secret ring; disable for sites that opt out), session resumption caches bounded, and 0-RTT (disabled).
4. Implement handshake DoS protections: handshake timeout 10 s, per-IP handshake rate limits, maximum concurrent handshakes, ClientHello size cap, renegotiation disabled (TLS 1.2 secure renegotiation refused), and metrics (`MET-hdd_tls_handshakes_total{version,result}`, `unknown_sni_total`).
5. Implement certificate hot reload semantics (atomic swap, in-flight connections continue with old certificates until close).
6. Implement HTTP→HTTPS redirect handling on port 80 (except ACME and verification paths), HSTS header emission per policy, and HTTP/2 coalescing rules (421 when the authority is not covered by the negotiated certificate).
7. Verify with external oracles: `openssl s_client` for version/cipher checks and SNI behavior, `testssl.sh` in lab/builder for a configuration report (oracle only), and Rust-based assertions.
8. Document the TLS policy and its rationale.
**Deliverables.**
- TLS layer, ADR, tests, docs
**Acceptance.**
- A1: TLS 1.0/1.1 handshakes fail; 1.2/1.3 succeed; the cipher list matches the policy (oracle output).
- A2: unknown and absent SNI are refused with the documented behavior.
- A3: certificate swap occurs without dropping existing connections.
- A4: 421 is returned for h2 requests whose authority is outside the certificate.
- A5: 0-RTT is disabled and renegotiation refused (tests).
**Tests.**
- Integration with real TLS clients; oracle checks; fuzz on ClientHello handling via rustls boundary.
**Notes.** AC-04 verifies live.
