### T-0347 · GeoIP and ASN enrichment
`P17` `[DP][OPS]` · deps: T-0346 · size: M · owner: dp
**Objective.** Provide country and ASN data for rules, analytics and risk signals.
**Steps.**
1. Implement the `maxminddb` reader wrapper with memory-mapped files, atomic hot reload on file replacement, caching of recent lookups (bounded), and graceful absence handling (all features depending on GeoIP show the capability requirement).
2. Document data sources and licenses: MaxMind GeoLite2 (account and license key required, EULA constraints) or DB-IP Lite (CC BY attribution) or operator-supplied; the platform never downloads without explicit operator configuration and an egress allowlist entry; record provenance in the profile (`geoip.source`).
3. Implement the update workflow: `hddctl geoip install <file>` with checksum and format validation; scheduled updates only when the operator configures credentials; version and age metrics (`MET-hdd_feed_age_seconds{feed="geoip"}`).
4. Implement enrichment in events (country, ASN, ASN org) and in the proxy pipeline for rules (country/ASN conditions), with privacy options (country-level only for display where org policy requires).
5. Implement ASN classification lists (mobile carriers, hosting/datacenter, education, government, Tor) from data files with provenance for `shared address` and bot scoring (T-0326, T-0340).
6. Implement UI affordances: country selector, ASN search; disabled states when the database is absent.
7. Test with a real MaxMind-format fixture database created in tests (using a writer crate or tool) covering IPv4/IPv6 edge cases.
8. Document accuracy limits.
**Deliverables.**
- GeoIP module, install tooling, tests, docs
**Acceptance.**
- A1: hot reload swaps databases without request errors.
- A2: absence of the database disables dependent features with clear messages (no panics).
- A3: lookups cost under 300 ns p99 (cached) and 2 µs uncached.
- A4: license and provenance fields are required for installation.
- A5: country rules in the rule builder fail validation without a database (`ERR-WAF-003`).
**Tests.**
- Unit/integration with fixture DB; benchmark.
**Notes.** The agent does not obtain licensed data on its own; the operator supplies it.
