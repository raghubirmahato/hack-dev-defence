### T-0335 · Rate-limit actions: 429 page, auto-ban and progressive penalties
`P17` `[DP][SEC][UI]` · deps: T-0334, T-0317 · size: M · owner: dp
**Objective.** Make limiting actions safe, consistent and escalating.
**Steps.**
1. Implement the 429 response: branded page/JSON (`ERR-VISITOR-429`), `Retry-After` seconds, `HDD-Ray-ID`, no rule names, `Cache-Control: no-store`.
2. Implement violation counting: each 429 increments a violation counter (Redis, local fallback) per key per rule; reaching N violations in the window yields a `rate_limit` `BanIntent` (first TTL 10 minutes, then the ladder), with cross-site rule not applicable (rate limiting is about volume).
3. Implement progressive penalties for repeat offenders across rules: second ban step increases limits strictness for that key for 24 h (halved limits) before ban.
4. Implement protections against self-DoS: do not count 429s toward limits again; ensure rejected requests are cheap (no body reading, immediate close for abusive keys).
5. Implement challenge as an action alternative (serve clearance challenge; cleared clients continue under the 2x limits).
6. Implement metrics and events (aggregated) and attention items for sustained limiting.
7. Provide UI copy for S-142 and S-061 consequences, including shared-IP hints.
8. Test with scripted bursts and legitimate bursty clients (page loads with many assets).
**Deliverables.**
- response handlers, violation logic, tests
**Acceptance.**
- A1: sustained abuse leads from 429 to ban per configuration (AC-11 scenario).
- A2: legitimate page loads (50 assets in 2 s) do not trigger limits at defaults (asset paths are excluded or weighted lower via asset classification).
- A3: 429 responses never reveal limit values beyond `Retry-After`.
- A4: banned keys recover after TTL (test clock).
- A5: rejected requests do not read bodies.
**Tests.**
- Integration burst tests (functional profile); benign page-load replay; unit: violation counters.
**Notes.** Asset classification (extension and path based) reduces false positives.
