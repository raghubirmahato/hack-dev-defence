### T-0132 · Identity abuse test suite against HDD's own login
`P06` `[SEC][QA]` · deps: T-0112, T-0119, T-0107 · size: L · owner: sec
**Objective.** Prove the identity surface resists the attacks in the matrix (AG-09, AG-17).
**Steps.**
1. Build an attack driver in `hdd-acceptance` (builder-local mode, targeting a locally started stack only) that performs: brute force from one IP, credential stuffing with 10,000 synthetic accounts, password spraying, distributed brute force on one account, account enumeration by timing and response, reset-token guessing, MFA code brute force, signup flooding, email bombing, session fixation, cookie tossing, CSRF forgeries, and lockout DoS against a victim.
2. Define success criteria: throttles engage at documented thresholds; no enumeration oracle (statistical tests on 1,000 samples per class); victim can still log in from known device during an attack; email volume bounded; no session fixation; no CSRF success.
3. Measure resource use during attacks (CPU, memory, hashing queue) and assert the limiter protects the process (no OOM, p99 latency of unrelated routes within budget).
4. Test with HDD's own WAF/rate limiter in front (dogfood configuration from P11 onward) and without it, recording both results.
5. Record all results with raw evidence and SHA-256; mark any threshold miss as FAIL with a diagnosis.
6. Generate the report section for AC-35 and AC-01.
7. Add regression tests for each discovered issue.
8. Document residual risks (distributed low-and-slow attacks, compromised email accounts).
**Deliverables.**
- attack drivers (builder-local only), reports, regression tests, docs
**Acceptance.**
- A1: statistical tests show no distinguishing signal for enumeration (p-value threshold documented).
- A2: all throttle thresholds match the specification.
- A3: unrelated route latency stays within budget during an attack.
- A4: no victim lockout from known devices.
- A5: findings are zero or fixed, with regression tests committed.
**Tests.**
- The driver suite is itself repeatable (`cargo xtask acceptance --only AC-35-abuse`).
- Safety: the driver refuses non-local targets (TargetGuard).
**Notes.** These tests run only against local stacks or the operator's pilot with the functional profile.
