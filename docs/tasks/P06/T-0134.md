### T-0134 · Bootstrap admin, platform roles and the first-run experience
`P06` `[OPS][SEC][UI]` · deps: T-0117, T-0125 · size: M · owner: ops
**Objective.** Provision the first platform owner securely and establish break-glass administration.
**Steps.**
1. Implement `hddctl admin bootstrap`: requires local root and database access, generates a random password written to a 0600 file (or delivered via systemd credentials), creates the `platform_owner` user (email from the profile), marks `must_enroll_mfa`, and prints only the path.
2. Implement the first-login flow: the bootstrap user must change the password and enroll MFA (TOTP and recovery codes, passkey recommended) before any other action; the generated password file is shredded after first login.
3. Implement platform staff management basics (invite staff by `platform_owner`, roles, removal) under the admin surface with step-up (full UI in P22).
4. Implement the platform first-run checklist (S-100 variant): SMTP configured and tested, legal pages, signup mode, backups configured, secondary DNS, status page, upstream DDoS info; each links to settings.
5. Implement break-glass documentation: SSH tunnel steps to `127.0.0.1:3000`/`:8000`, `hddctl` commands, and what to do if MFA is lost (CLI reset).
6. Ensure the bootstrap command is idempotent and refuses to create a second owner.
7. Add tests in a container simulating root and file permissions.
8. Add audit events.
**Deliverables.**
- `hddctl admin bootstrap|mfa-reset|staff`, first-run UI, docs, tests
**Acceptance.**
- A1: the password never appears on stdout/stderr or in logs.
- A2: the bootstrap user cannot access anything but enrollment until MFA is active.
- A3: running bootstrap twice does not create another owner.
- A4: file permissions of the credential file are 0600 and enforced.
- A5: break-glass access works with the admin surface unreachable from the public network (documented test).
**Tests.**
- Container-based integration test; unit: file permission checks; browser: first-login enrollment.
**Notes.** This task is the first to set up the pilot's operator account; it runs in P11 on the VPS as well.
