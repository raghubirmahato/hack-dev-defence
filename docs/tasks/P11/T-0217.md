### T-0217 · AC-00 preflight on the pilot (`hddctl preflight`)
`P11` `[OPS][QA]` · deps: T-0216 · size: L · owner: qa
**Objective.** Implement and run the preflight that guards every live action.
**Steps.**
1. Implement the complete AC-00 list: profile validates; VPS meets `min_resources`; kernel features and XDP mode recorded; required ports reachable; no conflicts on 53/80/443; NS and A records for the pilot zone resolve to the VPS from the runner's resolver and at least two named public resolvers; runner IP not in `admin_cidrs` (WARN if equal to the operator's workstation IP); AUP confirmation recorded; origin reachable directly while `lockdown_state=pending` and through HDD after; canary present and static; Postgres/Redis authenticated over TLS/socket; secrets files 0600; clocks sane (NTP); `egress_allowlist` covers each configured feed/CA/SMTP/resolver.
2. Add v5 additions: SMTP reachability and SPF/DKIM/DMARC preflight for the mail domain, GeoIP database presence (WARN/UNVERIFIED if absent), password breach list presence for `offline_list`, legal publication state, signup mode consistency, surfaces' hosts resolve and are served.
3. Print remediation text for each failure and abort on any FAIL; UNVERIFIED states list what the operator must supply.
4. Run it from the runner against the pilot VPS and capture real output with hashes.
5. Verify the run does not modify state (read-only), except temporary canary fetches.
6. Save the evidence and update STATUS.
7. Re-run after fixes until PASS or UNVERIFIED with reasons.
8. Make preflight a prerequisite of all later live checks (the runner refuses to continue otherwise).
**Deliverables.**
- `hddctl preflight` full, evidence logs
**Acceptance.**
- A1: preflight fails with a clear message when the runner IP is in `admin_cidrs` (negative test).
- A2: every item has PASS/FAIL/UNVERIFIED with evidence and remediation.
- A3: output tails and the SHA-256 of the full log are pasted in the gate report.
- A4: running preflight twice yields the same results (no state changes).
- A5: later checks refuse to run if preflight is not PASS.
**Tests.**
- Unit: item evaluators; integration: simulated failures; live: pilot run.
**Notes.** Preflight output is also the template for `docs/ENV.md` refresh at P28.
