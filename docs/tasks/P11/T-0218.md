### T-0218 · First live checks: AC-03 basic, AC-04 staging, AC-05 canary subset
`P11` `[QA][DP][DNS]` · deps: T-0209, T-0217 · size: L · owner: qa
**Objective.** Prove DNS, ACME staging and the proxy path work on the real internet.
**Steps.**
1. AC-03 (basic): query the VPS directly over UDP and TCP for the pilot subzone names (A, NS, SOA, TXT); check AA flag, NXDOMAIN with SOA, NODATA, REFUSED for a foreign zone, EDNS payload cap, TC behavior on a deliberately large TXT; then query via at least two public recursive resolvers once delegation propagated; run `dig +trace` from the runner.
2. AC-04 (staging): request a staging certificate for `test_hostname` via HTTP-01 and a DNS-01 wildcard on the pilot zone; validate chains against the staging root; verify TLS 1.2+ only, h2 negotiated, unknown/absent SNI refused, HSTS/redirect correct; force a short-window renewal on staging; check CT entry (staging log if applicable).
3. AC-05 (canary subset): fetch `static.css` through HDD and directly (before lockdown) and compare SHA-256; check `ok.txt`; verify `Server: Hack-Dev-Defence`, absence of origin `Server`/`X-Powered-By`, security headers, `HDD-Ray-ID`; run the `echo-headers` check for `X-Forwarded-For` and `HDD-Connecting-IP` if the sidecar is installed (else UNVERIFIED capability_not_supplied).
4. Apply the `functional` profile limits and the inspect-first gate does not apply (no attack payloads here).
5. Record raw evidence (DNS answers, headers, hashes) with SHA-256 logs.
6. Fix failures at the root cause under the failure budget (R-14).
7. Update the runner registry statuses and the capability matrix.
8. Capture timings for DNS and TLS handshakes as baselines.
**Deliverables.**
- check implementations for AC-03 (basic), AC-04 (staging), AC-05 (subset), evidence
**Acceptance.**
- A1: AC-03 basic PASS with answers from the VPS and from two public resolvers.
- A2: AC-04 staging PASS (or UNVERIFIED with a precise reason).
- A3: AC-05 canary byte-exact hash PASS.
- A4: unknown SNI refusal is shown with oracle output.
- A5: evidence files exist with SHA-256.
**Tests.**
- Live runs by the runner; oracles: `dig`, `delv` (for validation behavior), `openssl s_client`.
**Notes.** DNSSEC is not claimed; `delv` is used to demonstrate expected behavior only.
