### T-0214 · Telemetry v0 across services
`P11` `[OPS]` · deps: T-0207, T-0208 · size: M · owner: ops
**Objective.** Make the pilot observable from day one.
**Steps.**
1. Implement the shared telemetry crate module: `tracing` JSON logs with redaction filters and request IDs, `metrics` with a Prometheus exporter on a private listener (`HDD_METRICS_BIND`), `/healthz` (process alive), `/readyz` (dependencies ready) per service.
2. Implement the baseline metric set for proxy and DNS from B9 (requests, durations, TLS handshakes, unknown SNI, DNS queries/rcodes, config revision, panics, build info).
3. Implement a host collector in `hdd-shield` v0 (library) reading `/proc/net/dev`, `/proc/net/snmp`, conntrack counters, softirq stats, and load, exposing them as metrics (the shield state machine is P26).
4. Provide an operations doc for scraping (a Prometheus instance is the operator's choice; provide a minimal config and a Grafana dashboard JSON generated by `xtask grafana` from Rust structs).
5. Implement log rotation and retention (journald or file with logrotate-equivalent, 14 days default) and the log redaction test (no secrets).
6. Implement the external heartbeat sender (optional) to `alerts.heartbeat_url_env` every 60 s with a signed payload and jitter.
7. Implement the panic hook that increments `MET-hdd_panics_total` and logs a redacted backtrace summary.
8. Test the endpoints from the runner through the SSH tunnel.
**Deliverables.**
- telemetry module, dashboards-as-code v0, docs, tests
**Acceptance.**
- A1: `/metrics` is reachable only on the private listener (self-scan from outside fails).
- A2: all baseline metrics appear with labels from B9 (golden metrics list).
- A3: logs contain no secrets or request bodies (scanner over 10k lines).
- A4: heartbeats arrive at the configured sink at the configured interval.
- A5: a forced panic increments the metric and the process continues (task isolation test).
**Tests.**
- Integration: scrape tests; log scanner; panic isolation test.
**Notes.** AC-20 verifies alerts and heartbeats in full in P28.
