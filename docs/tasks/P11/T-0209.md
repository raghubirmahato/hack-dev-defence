### T-0209 · ACME client v0 (staging): HTTP-01 issuance and hot reload
`P11` `[DP][OPS][SEC]` · deps: T-0198, T-0208 · size: L · owner: dp
**Objective.** Obtain a real staging certificate for `test_hostname` and serve it without restart.
**Steps.**
1. Spike `instant-acme` capabilities (account creation, orders, HTTP-01, DNS-01, wildcard, ARI support, error mapping) and record the ADR (ARI availability, API surface, maintenance).
2. Implement the ACME worker: account creation per directory (staging default), key generation (ECDSA P-256 for certificates; account key P-256), order creation for approved names, authorization handling, HTTP-01 token publication to Redis with Postgres fallback and TTL, finalization with CSR from `rcgen`-style generation (private key encrypted and stored via the envelope module), and certificate retrieval.
3. Implement hot reload: on issuance, write the certificate with a snapshot revision; the proxy swaps its certificate map atomically without dropping connections.
4. Integrate the order state machine and the budget service (T-0198) so staging attempts are budgeted too.
5. Implement CAA pre-check and the DNS pre-check for the name pointing at HDD before ordering (avoid wasted attempts).
6. Implement retries/backoff and structured error mapping to user-visible reasons.
7. Implement the renewal scheduler skeleton (one third of lifetime or ARI hint) using the plan from T-0198 and verify with forced short windows on staging.
8. Test locally against the Pebble-class server and live against the staging directory only when the pilot is delegated.
**Deliverables.**
- ACME worker v0, ADR, tests, runbook notes
**Acceptance.**
- A1: a staging certificate for `test_hostname` is issued over HTTP-01 on the live pilot (after STOP #1) and validates against the staging root.
- A2: the proxy serves the new certificate within 2 s of issuance without dropping existing connections (test with a long-lived h2 connection).
- A3: production directory use is refused unless `acme_production_enabled` is set (flag tested).
- A4: budget service blocks excess staging attempts in tests.
- A5: private keys exist only encrypted at rest (database inspection test).
**Tests.**
- Integration with the local ACME server; live staging test (AC-04) when allowed; unit: scheduler timing.
**Notes.** Production issuance happens once, with the operator's approval, in P31 (T-0538).
