### T-0421 · Global domains view and domain actions (S-105)
`P22` `[UI][API]` · deps: T-0417, T-0153, T-0171 · size: M · owner: web
**Objective.** Give operators a platform-wide view of protected domains and the means to suspend abusive ones.
**Steps.**
1. Implement `GET P/domains` with filters (state, integration mode, WAF mode, verification state, abuse flag, certificate state, org) and search by hostname (exact/suffix), sorted by last state change; columns show domain, org, state, mode, WAF mode, cert expiry, last traffic time, abuse flags.
2. Implement domain detail drawer: lifecycle history (state machine transitions with actors), verification evidence summary (method, when), DNS delegation status, origin host (hostname only, resolved IPs masked to /24 for staff without `platform.domain.suspend`), recent attention items, and abuse reports referencing the domain.
3. Implement suspend/unsuspend (reason, optional customer message, step-up): suspension makes the proxy answer with the neutral suspended page (S-148) for that host and DNS continue per policy (zone remains served unless the reason is DNS abuse, selectable), revokes certificate renewal for abuse cases, records audit events and notifies owners (template with the reason category, not internal notes).
4. Implement the admin-assisted transfer (`POST /platform/domains/{dom}/transfer`) with dual confirmation (current owner consent evidence or dispute resolution reference), step-up, audit and notifications to both orgs.
5. Implement bulk selection safeguards: bulk suspend requires typed confirmation of the count and is capped at 25 per action.
6. Implement domain-claim conflict handling UI (two orgs attempting the same domain): show evidence, resolve by verification freshness, document manual resolution steps.
7. Write tests: filters/search, suspension effects propagate to the data plane within 2 s (integration with the proxy), S-148 content has no tenant details, transfer flow with RLS correctness, bulk caps, and audit completeness.
**Deliverables.**
- API, screen, propagation hooks, tests
**Acceptance.**
- A1: a suspended domain serves the neutral page within 2 s and no origin traffic occurs (origin access log in the test shows none).
- A2: the transfer flow moves all domain-scoped data atomically and keeps history.
- A3: bulk actions above the cap are refused with a clear error.
- A4: owners receive the notification without internal notes.
- A5: all actions produce audit events with reasons.
**Tests.**
- Integration with proxy; browser e2e; RLS tests.
**Notes.** Suspension is a platform-level action distinct from the owner's "pause protection".
