### T-0044 · Data display: table, key-value list, timeline, badges, cards, diff viewer
`P02` `[UI]` · deps: T-0043 · size: L · owner: ux
**Objective.** Provide the data presentation components that most screens depend on.
**Steps.**
1. `DataTable`: semantic table, caption, sortable headers as buttons (`aria-sort`), column visibility menu, density toggle, row selection with a bulk action bar, sticky header, empty state, loading skeleton, responsive stacked-card mode below 640 px, CSV export link slot, and cursor pagination integration.
2. Server-driven sorting and filtering through URL parameters; filter chips with removal buttons; "clear all".
3. `KeyValueList` (`dl`) with copy affordances; `Timeline` (ordered list with `<time>`); `Badge`, `StatusDot`, `SeverityPill` (icon+text+color) and `Tag`.
4. `Card` and `StatCard` (label, tabular value, delta with text, optional sparkline slot, optional unknown-state).
5. `DiffViewer` (unified and side-by-side, line numbers, additions/removals announced by text prefix and not color alone, collapsible context).
6. Virtualization strategy for very long lists is deferred to the live feed (T-0086) but the table API reserves `aria-rowcount`/`aria-rowindex`.
7. Define empty/loading/error/permission states per component using T-0021 patterns.
8. Provide print styles for tables.
**Deliverables.**
- components, CSS, docs, snapshot tests, example data fixtures used only in the gallery (explicitly labeled synthetic)
**Acceptance.**
- A1: tables pass axe (headers, scope, caption) and keyboard sorting works.
- A2: the stacked-card mode keeps all data and labels.
- A3: SeverityPill never relies on color alone.
- A4: StatCard has an `Unknown (reason)` state tested.
- A5: the diff viewer is understandable without color (tests check prefix characters and text labels).
**Tests.**
- Browser tests at 360 and 1280; snapshot tests; unit tests for query-string state serialization.
**Notes.** Gallery data is synthetic and labeled "Example data" visibly; it must never appear in product screens (R-16).
