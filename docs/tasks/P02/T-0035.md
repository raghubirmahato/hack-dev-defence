### T-0035 · CSS architecture, cascade layers and the stylesheet bundler
`P02` `[UI]` · deps: T-0032 · size: M · owner: ux
**Objective.** Establish maintainable CSS with predictable specificity and enforceable limits.
**Steps.**
1. Define the layer order: `reset, tokens, base, layout, components, patterns, utilities, overrides` and document what belongs where.
2. Write the reset/base styles: box-sizing, margin reset, `color-scheme`, focus-visible default, `prefers-reduced-motion`, forced-colors, selection, scrollbar styling with fallback, `hidden` attribute behavior, `[inert]`.
3. Define naming (`hdd-` prefix, BEM-lite) and the rule that components never style other components' internals.
4. Implement bundling with `lightningcss` inside `xtask`: imports resolved, nesting lowered, minified, source maps for development builds only (never shipped), vendor prefixes per browser targets (documented), unused CSS report.
5. Split bundles: `core.css` (tokens, base, layout, components used on every page) and per-surface bundles (`public.css`, `app.css`, `admin.css`) loaded conditionally to keep the budget.
6. Implement a CSS size and rule-count budget check: core+surface at most 60 KB gzip, hand-written CSS at most 12,000 lines (DEV-V5-002).
7. Add a CSS lint: no `!important` outside `overrides`, no inline styles in templates, no ID selectors, no hex literals, no px font sizes in components.
8. Document browser support targets (last two major versions of Chromium, Firefox, Safari) and progressive enhancement rules.
**Deliverables.**
- `crates/hdd-ui/css/{reset,base,layout,utilities}.css`, layer manifest, bundler in xtask, lint
**Acceptance.**
- A1: bundles are produced with hashed names and listed in `assets.json`.
- A2: CSP can run with `style-src 'self'` (no inline styles anywhere; verified by T-0075 tests later and a static scan now).
- A3: lint violations fail `xtask ui verify`.
- A4: size budgets are reported and enforced.
- A5: unused CSS report exists and is reviewed at gate.
**Tests.**
- Unit tests for the lint rules; golden tests for bundle output; budget test with an artificially large stylesheet.
**Notes.** The CSS cap in DEV-V5-002 includes only hand-written CSS, not generated tokens.
