### T-0031 · Typography tokens and self-hosted fonts
`P02` `[UI]` · deps: T-0030 · size: S · owner: ux
**Objective.** Deliver readable, fast typography with no third-party requests.
**Steps.**
1. Select the sans and mono fonts per B11.3 (Inter and JetBrains Mono under the SIL Open Font License) and record the licenses, versions and checksums in `design/LICENSES.md`.
2. Subset to Latin and Latin-Extended with a Rust-based or vetted tool run by `xtask ui build` (no Python in the pipeline); produce WOFF2 files and verify sizes meet the budget (target at most 60 KB for the sans variable subset, 40 KB for mono regular).
3. Define `@font-face` with `font-display: swap`, `unicode-range`, and preload hints for the critical weight only.
4. Create `design/tokens/type.toml` (scale, line heights, weights, tracking) and generate CSS custom properties; define utility classes for headings `h1`..`h6` and `text-*` roles.
5. Define fallbacks (`system-ui` stacks) with `size-adjust` to limit layout shift when swapping.
6. Define tabular numerals and `font-feature-settings` for tables and counters; define slashed zero for mono where useful.
7. Verify rendering at 200% and 400% zoom and with user stylesheets overriding line height and letter spacing (WCAG 1.4.12).
8. Document how to add a script/locale-specific font later without touching components.
**Deliverables.**
- `crates/hdd-ui/assets/fonts/*.woff2`, `design/tokens/type.toml`, generated `typography.css`
- font license records
**Acceptance.**
- A1: no request leaves the origin for fonts (verified in the browser harness network log).
- A2: font assets meet the size budgets.
- A3: layout shift from font swap is under 0.02 CLS in the gallery page test.
- A4: text spacing override test passes (no clipped text).
- A5: license texts are bundled and referenced from the `/legal` area.
**Tests.**
- Browser test measuring CLS and network requests on the gallery; text-spacing override test using injected CSS.
**Notes.** If subsetting tooling is not available in Rust, record an ADR allowing a pinned build-time tool and keep generated fonts in the repo.
