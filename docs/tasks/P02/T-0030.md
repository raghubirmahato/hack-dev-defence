### T-0030 · Color tokens, themes and the contrast checker
`P02` `[UI][QA]` · deps: T-0029 · size: M · owner: ux
**Objective.** Implement the color system of B11.2 as data, generate CSS, and make contrast regressions impossible.
**Steps.**
1. Create `design/tokens/color.toml` with dark and light sets exactly as specified in B11.2, plus semantic aliases (`surface`, `surface-raised`, `text`, `text-muted`, `border`, `border-control`, `accent`, `danger`, `warning`, `success`, `info`, `focus`, `link`).
2. Add the severity palette (critical, high, medium, low, info) and the 8-color chart series for both themes, plus selection and hover tints.
3. Implement `xtask contrast-check` (WCAG relative-luminance formula) that evaluates a declared list of foreground/background pairs with targets (4.5, 3.0) and fails the build if any pair falls short; the pair list lives in `design/tokens/contrast-pairs.toml`.
4. Generate `tokens.css` with `:root[data-theme="dark"]`, `:root[data-theme="light"]`, and `@media (prefers-color-scheme)` defaults for `data-theme="system"`, plus `@media (forced-colors: active)` overrides mapping to system colors.
5. Generate a Rust module with the series colors for the SVG chart kit so charts and CSS never drift.
6. Add a report `acceptance-ui/contrast.json` listing every pair with ratio and pass/fail, included in gate reports.
7. Define the rules for adding colors: new tokens require a pair entry and a use case; ad-hoc hex values in CSS or templates fail a lint (`xtask ui lint`).
8. Document color usage guidance (never color alone; severity always with icon and text).
**Deliverables.**
- `design/tokens/color.toml`, `design/tokens/contrast-pairs.toml`
- generated `crates/hdd-ui/assets/tokens.css` and `src/tokens.rs`
- `xtask contrast-check`, `xtask ui lint` (hex literal ban)
**Acceptance.**
- A1: all pairs in B11.2 meet their targets; the report is generated.
- A2: changing one token to a failing value makes `xtask contrast-check` fail (demonstrated).
- A3: forced-colors CSS uses only system colors.
- A4: a hex literal in a component stylesheet fails `xtask ui lint`.
- A5: dark and light CSS is generated from the same source of truth with no manual duplication.
**Tests.**
- Unit tests for the luminance and ratio functions against reference values; golden test for generated CSS.
**Notes.** Contrast numbers quoted in B11.2 were computed with this formula and must match the checker output.
