### T-0048 · Command palette, theme/locale/density toggles and the user menu
`P02` `[UI]` · deps: T-0042, T-0043 · size: M · owner: ux
**Objective.** Implement the global utilities that appear in every frame.
**Steps.**
1. `CommandPalette` as a dialog with a combobox and listbox: opening with Ctrl/Cmd+K and from a visible button; results grouped (Navigate, Domains, Actions, Recent); server-provided results already permission-filtered; keyboard handling (arrows, Enter, Esc, Home/End); loading and empty states; no results leaking other tenants.
2. `ThemeToggle` (system, dark, light) with `aria-pressed` radio semantics, persisted to account and cookie; the initial theme is set server-side from the cookie to avoid flash; a tiny nonce-allowed script handles first paint only if necessary (≤ 300 bytes) and is documented in the CSP notes.
3. `LocaleSwitcher` and `DensityToggle` (comfortable, compact) with the same persistence rules.
4. `UserMenu` (profile, security, sessions, sign out, shortcuts, help) as a Menu component.
5. `NotificationBell` button with accessible count, popover list, mark-all-read, link to the notification center.
6. `HelpMenu` and the shortcuts overlay (`?`) listing active keyboard shortcuts with the ability to disable single-key shortcuts (WCAG 2.1.4).
7. Define what is stored where (cookie names, account preferences) and ensure no third-party storage.
8. Document the ranking algorithm for palette results (exact match, prefix, recency).
**Deliverables.**
- components, island JS (palette keyboard + fetch of results via HTMX), docs
**Acceptance.**
- A1: palette opens via keyboard and button, traps focus, closes with Esc and restores focus.
- A2: single-key shortcuts can be disabled and never fire in text fields.
- A3: theme choice persists and no flash occurs on reload (CLS and visual test).
- A4: results never include resources outside the user's permissions (server tests in P07).
- A5: all utilities are reachable in forced-colors mode.
**Tests.**
- Browser tests for keyboard, persistence and focus; unit tests for ranking.
**Notes.** The server-side data endpoints arrive in T-0142; this task builds the UI and a contract test for the payload shape.
