### T-0232 · Access lists screen (S-063) with self-lockout preview and CSV import
`P12` `[UI][API][SEC]` · deps: T-0237 · size: L · owner: api
**Objective.** Manage allow/deny/challenge entries by IP, CIDR, country and ASN safely.
**Steps.**
1. Define `access_entries` handling: kind (ip, cidr, country, asn), action (allow, deny, challenge), `skip_inspection` (allow only; documented risk with typed confirmation), expiry (optional; mandatory for allow entries over /16 IPv4 or /48 IPv6), note, created by.
2. Implement validation: CIDR parsing, canonicalization, prefix limits (deny entries wider than /8 IPv4 or /32 IPv6 require typed confirmation), country codes against ISO list (requires GeoIP DB else `ERR-WAF-003`), ASN numbers; reject private/loopback ranges for deny entries unless the owner explicitly confirms (these are never client IPs behind public proxies).
3. Implement the **self-lockout preview**: before saving, compute whether the user's current IP (as HDD sees it) or session country/ASN is affected; block with `ERR-WAF-007` unless acknowledged; also warn about HDD platform IPs and the origin IP.
4. Implement CSV import with a validation preview (row-level errors, duplicates, overlaps), size limit (5,000 rows), and atomic commit.
5. Implement the country selector (searchable, keyboard-operable, regions grouping) and ASN lookup helper (names from the ASN database if present).
6. Implement overlap resolution explanation (allow beats deny at equal specificity? defined rule: most specific wins; at equal specificity allow wins unless the entry is a platform deny) and show effective results for a tested IP via a "Test an IP" tool.
7. Implement expiry job and notifications.
8. Add audit events, revisions, tests.
**Deliverables.**
- model, validation, UI, tests
**Acceptance.**
- A1: an entry that would block the user's own IP is refused without acknowledgment.
- A2: the "Test an IP" tool returns the same decision as the data plane matcher (shared crate).
- A3: wide deny entries require typed confirmation.
- A4: CSV import is atomic and reports row errors.
- A5: country rules without GeoIP are rejected with a clear explanation.
**Tests.**
- Unit: matcher semantics and overlap table; proptest on CIDR set operations; browser flows; integration: import.
**Notes.** The tenant allowlist never overrides the platform never-ban semantics in reverse (platform bans can still apply).
