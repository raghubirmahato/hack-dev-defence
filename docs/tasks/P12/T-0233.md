### T-0233 · Honeypots and decoys screen (S-095)
`P12` `[UI][API][SEC]` · deps: T-0237 · size: M · owner: ui
**Objective.** Configure tripwires that expose scanners without trapping real users.
**Steps.**
1. Define honeypot model (path pattern, kind: default/custom, action: ban, optional response mode: 404 normal, tarpit, fake content) and defaults by `site.platform`: `/.env`, `/.git/config`, `/phpmyadmin`, `/actuator/env`, `/.aws/credentials`, `/server-status`, `/wp-config.php.bak`, `/backup.zip`, plus `/wp-admin` and `/wp-login.php` for **non-WordPress** sites only.
2. Implement the UI: default list with toggles, custom paths with validation (no overlap with real routes: warn if the path returns 2xx on the origin from recent traffic samples), platform note about WordPress, and explanation of cross-site context ("hits from other websites' pages do not ban").
3. Implement the conflict check: a honeypot path that real users reach (observed 2xx from many distinct sessions) is flagged and cannot be enabled without acknowledgment.
4. Implement hidden-form-field honeypots as an **opt-in** feature requiring the site owner to add a field (HDD does not rewrite responses); provide the snippet and the detection of a filled field in form posts (field name configurable).
5. Implement decoy response modes carefully: `404` default; `tarpit` (slow response with bounded resources) disabled by default and capped; no fake sensitive content is generated.
6. Publish via the policy service and audit.
7. Implement counters of honeypot hits per path.
8. Add tests for default sets per platform.
**Deliverables.**
- model, UI, tests
**Acceptance.**
- A1: WordPress sites do not receive `/wp-admin` or `/wp-login.php` honeypots.
- A2: honeypot paths with observed legitimate traffic cannot be enabled silently.
- A3: tarpit is capped (duration and concurrency) and off by default.
- A4: hidden-field honeypots are only active when the owner opts in.
- A5: defaults match the attack matrix lists (drift test).
**Tests.**
- Unit: defaults and conflict logic; browser: toggles; integration: snapshot publication.
**Notes.** Engine behavior: T-0309 and the ban policy (T-0317).
