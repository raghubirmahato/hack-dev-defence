### T-0272 · Field-kind context policy and learned parameter shapes
`P14` `[DP][API][SEC]` · deps: T-0251, T-0265, T-0266 · size: L · owner: waf
**Objective.** Apply the C4.6 policy table and add optional positive-security learning.
**Steps.**
1. Implement the policy table lookups for SQLi families by field kind and strictness (Balanced/Paranoid), including `code_friendly` and `shared` options, and expose them through the verdict explanation.
2. Implement benign-name safeguards: apostrophes inside names/addresses never contribute to hard families unless followed by SQL syntax; `#` as number sign is only a comment signal after a quote.
3. Implement **learning mode** (opt-in): observe legitimate traffic (requests that returned 2xx/3xx and had no matches) per (path pattern, method, parameter name) and record shape statistics: character class histogram, min/max length, numeric-only ratio, enum cardinality; store only aggregates (no values) in `param_schemas.observed` with sample counts, requiring a minimum of 500 samples and 7 days before suggestions.
4. Implement enforcement modes for learned shapes: `log` (record deviations as soft signals), `enforce` (deviations score as soft 3; hard families remain independent); exceptions allowed; never enforce on parameters with high variance.
5. Implement UI hooks for S-057 (suggestions list, accept/reject, enforce toggle) and APIs.
6. Implement privacy safeguards: the learner never stores values, only aggregate histograms with k-anonymity thresholds (do not store categories with fewer than 20 distinct observations); reset and delete controls.
7. Write tests with synthetic traffic generated through the real proxy harness.
8. Document the privacy model in the privacy page and S-057.
**Deliverables.**
- policy lookup, learner, APIs, tests, docs
**Acceptance.**
- A1: policy outcomes match the C4.6 table for all kind x family combinations (table test).
- A2: the learner stores no raw values (schema and database inspection test).
- A3: deviations from learned numeric-only parameters add soft score only in enforce mode.
- A4: learned shapes can be reset and deleted.
- A5: `code_friendly` lowers soft weights but not hard detections.
**Tests.**
- Table tests; integration with the proxy harness; privacy inspection test.
**Notes.** V4 of the shield (C3.3).
