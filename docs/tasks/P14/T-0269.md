### T-0269 · Hard family H5: blind, time-based, error-based and out-of-band functions
`P14` `[DP][SEC]` · deps: T-0264 · size: L · owner: waf
**Objective.** Detect inference and exfiltration payloads based on SQL function usage.
**Steps.**
1. Implement function-call detection (token `Function` followed by `(`, case-insensitive, whitespace/comment tolerant) for: `sleep`, `benchmark`, `pg_sleep`, `waitfor delay|time`, `dbms_pipe.receive_message`, `dbms_lock.sleep`, `randomblob` (with large argument), `generate_series` (large), `extractvalue`, `updatexml`, `exp(~`, `floor(rand(`, `utl_inaddr.get_host_address`, `utl_http.request`, `xp_dirtree`, `xp_fileexist`, `load_file`, `lo_import`, `pg_read_file`, `openrowset`, `opendatasource`, `dbms_xmlgen`, `ctxsys.drithsx.sn`, plus clause forms `into outfile`, `into dumpfile`.
2. Implement boolean-extraction shapes: `if(ascii(substring((select ...),1,1))>n, sleep(5), 0)`, `case when (select ...) then ... else ... end`, `and (select count(*) from ...)>0`, `substring(...)=...`, `ascii(...)`, `ord(...)`, `mid(...)`, `length(...)` inside boolean connectors after breakout.
3. Define subtypes `time_based`, `error_based`, `out_of_band`, `boolean_blind`; hardness hard for function-call syntax with SQL-structured arguments (numeric or subselect) or after breakout; soft for isolated function names in prose ("benchmark results", "sleep(5 hours)" as natural words without parentheses).
4. Add numeric-argument sanity (sleep with 0 to 3600), the presence of a delay in seconds is not required but raises confidence.
5. Handle DNS exfil constructs (`concat(version(),'.attacker.invalid')` with `load_file(concat('\\\\',...))`) as inert strings with `.invalid` hosts.
6. Write rule metadata; counter-examples: "benchmark(ing) study", "extractvalue of the product" (no parentheses), code samples in documentation fields flagged as soft with explanation.
7. Link ATK-006 to ATK-009; fixtures (≥ 100).
8. Validate against benign corpora and bench performance.
**Deliverables.**
- H5 detector, rules, fixtures, tests
**Acceptance.**
- A1: `1 AND SLEEP(5)`, `'; WAITFOR DELAY '0:0:5'--`, `' || pg_sleep(5)--`, `' AND (SELECT 1 FROM (SELECT SLEEP(5))a)--`, `' AND extractvalue(1,concat(0x7e,version()))--` are hard.
- A2: natural-language uses of the words are not hard.
- A3: function-call detection tolerates comment/space/encoding obfuscation (`SLE/**/EP(5)` is invalid SQL and soft; `SLEEP /**/ (5)` is hard).
- A4: boolean-extraction shapes are detected as hard after breakout.
- A5: zero false positives on benign corpora.
**Tests.**
- Table (200) / proptest / benign gate; bench.
**Notes.** The behavioral latency correlation (T-0277) complements this static detector.
