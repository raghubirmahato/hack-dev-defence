### T-0270 · Hard family H6: schema and metadata discovery in SQL context
`P14` `[DP][SEC]` · deps: T-0264 · size: M · owner: waf
**Objective.** Detect reconnaissance of database structure without flagging documentation.
**Steps.**
1. Implement detection of metadata object names: `information_schema.(tables|columns|schemata|routines)`, `pg_catalog`, `pg_tables`, `pg_user`, `pg_shadow`, `sysobjects`, `syscolumns`, `sys.tables`, `sys.databases`, `sqlite_master`, `sqlite_schema`, `all_tables`, `user_tables`, `all_tab_columns`, `mysql.user`, `mysql.db`, `performance_schema`, `v$version`, `@@version`, `@@datadir`, `@@hostname`, `version()`, `database()`, `schema()`, `current_user`, `session_user`, `user()`, `current_database()`.
2. Require **SQL context** for hard classification: the name appears together with `select|from|union|where|concat|group_concat|limit` tokens within a 12-token window, or after a breakout; isolated mentions are soft 2 (documentation, tutorials).
3. Define subtype `schema_discovery`; hard in the SQL-context case; link ATK-010.
4. Handle quoting variations (`information_schema . tables`, backticks, brackets, double quotes), schema-qualified names, comment obfuscation, hex-encoded names `0x696e666f...` flagged soft+evasion.
5. Counter-examples: docs and Q&A text mentioning `information_schema`, blog posts about `pg_catalog` (with no select context), "current_user" in plain English? (identifier in prose "the current user" with a space is not matched).
6. Write rule metadata and fixtures (≥ 60).
7. Test with code-friendly site option (T-0272).
8. Validate against benign corpora.
**Deliverables.**
- H6 detector, rules, fixtures, tests
**Acceptance.**
- A1: `' UNION SELECT table_name FROM information_schema.tables--` and `SELECT * FROM sqlite_master` shapes are hard.
- A2: a prose sentence about `information_schema` is soft only.
- A3: obfuscated spacing/quoting variants are detected.
- A4: `code_friendly` sites lower soft weights but still hard-detect SQL-context shapes.
- A5: zero false positives on benign corpora.
**Tests.**
- Table (120) / benign gate.
**Notes.** Developer-oriented sites need the `code_friendly` option documented in S-057.
