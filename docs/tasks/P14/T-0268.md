### T-0268 · Hard family H4: stacked queries and dangerous statements
`P14` `[DP][SEC]` · deps: T-0264 · size: M · owner: waf
**Objective.** Detect statement chaining and administrative procedure abuse.
**Steps.**
1. Implement detection of `;` (statement terminator) followed (ignoring whitespace/comments) by DDL/DML/administrative keywords: `drop`, `alter`, `create`, `truncate`, `insert`, `update`, `delete`, `exec`, `execute`, `declare`, `shutdown`, `grant`, `revoke`, `merge`, `call`, `copy`, `load`, `attach`, `pragma`, `vacuum`, `set`, `use`, `begin`, `commit`, `rollback`, `waitfor`, `backup`, `restore`.
2. Detect dangerous procedures and objects regardless of preceding `;`: `xp_cmdshell`, `sp_executesql`, `sp_configure`, `sp_oacreate`, `sp_makewebtask`, `xp_regread`, `master..`, `sysdatabases`, `COPY ... TO PROGRAM`, `LOAD DATA INFILE`, `SELECT ... INTO OUTFILE|DUMPFILE`, `pg_ls_dir`, `lo_export`.
3. Define subtype `stacked` (and `dangerous_procedure`) with hardness hard when preceded by a breakout quote/paren or in numeric context or when the statement keyword pair forms valid syntax (e.g., `drop table x`, `insert into x`, `update x set`, `delete from x`); otherwise soft.
4. Handle `;` encoded as `%3b`, `&#59;`, fullwidth `；` (folded), and splitting by comments.
5. Handle Class B payload fixtures (e.g., `'; DROP TABLE users--`) strictly as inert strings in tests and the inspect API (never live to non-sandbox targets).
6. Write rule metadata; counter-examples: CSS or JS code in free-text fields with semicolons and words like "update" or "set" ("Please update; set up later"), semicolon-separated lists in prose.
7. Link ATK-005, ATK-022; create fixtures (≥ 60).
8. Validate against benign corpora.
**Deliverables.**
- H4 detector, rules, fixtures, tests
**Acceptance.**
- A1: `'; DROP TABLE users--`, `1; UPDATE users SET admin=1`, `; EXEC xp_cmdshell('...')`, `'; shutdown --` are hard.
- A2: prose with semicolons and verbs ("Please update; set it later") is not hard.
- A3: encoded semicolons are detected.
- A4: `INTO OUTFILE` and `COPY ... TO PROGRAM` shapes are hard.
- A5: zero false positives on benign corpora.
**Tests.**
- Table (120) / proptest / benign gate.
**Notes.** Class B fixtures are tagged and excluded from live runs by the loader.
