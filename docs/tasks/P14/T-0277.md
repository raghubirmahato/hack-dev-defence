### T-0277 · Time-based attack behavioral detector
`P14` `[DP][SEC]` · deps: T-0269, T-0261 · size: M · owner: dp
**Objective.** Catch blind time-based injection even when the payload evades static signatures.
**Steps.**
1. Implement the latency-correlation detector in the proxy: for each (site, path pattern, method), maintain a baseline of origin response time (EWMA and p95 over a rolling window); record per-request latency and the request's parameter shape signature (names only).
2. Flag anomalies: requests from one client key that produce origin latency exceeding baseline p99 by more than 3 s repeatedly (≥ 3 within 60 s) and whose parameters contain any SQL-punctuation soft signal; emit event `time_based_suspected` with a soft score and an attention item.
3. Implement the optional **tarpit-on-suspicion** action: when the same client key sends repeated suspicious time-delay-shaped requests, respond to subsequent suspicious requests with a bounded delay (≤ 2 s, concurrency capped) to waste attacker time without consuming unbounded resources; off by default and only in Paranoid.
4. Ensure the detector does not fire on legitimately slow endpoints (baseline learning, minimum sample counts, per-path learned slowness).
5. Implement metrics and events; integrate with the ban policy as a soft intent.
6. Test with a local origin implementing controllable `sleep` endpoints and a script that produces blind-style request patterns.
7. Add configuration and UI explanation.
8. Document limitations (requires traffic; thresholds).
**Deliverables.**
- detector, optional tarpit, tests
**Acceptance.**
- A1: a blind time-based probing pattern against a slow-on-demand local endpoint is flagged within 3 probes.
- A2: legitimately slow endpoints (baseline-slow) are not flagged.
- A3: the tarpit respects caps (duration, concurrency) and is off by default.
- A4: events carry subtype `time_based_suspected` with no payload values.
- A5: the detector adds under 10 µs to the hot path.
**Tests.**
- Integration with the proxy harness; unit: baseline math; benchmark.
**Notes.** Static detection (H5) remains the primary defense.
