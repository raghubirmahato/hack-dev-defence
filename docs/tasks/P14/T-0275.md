### T-0275 · NoSQL, LDAP, XPath and GraphQL injection detectors
`P14` `[DP][SEC]` · deps: T-0250, T-0264 · size: L · owner: waf
**Objective.** Cover non-SQL query-language injections that target the same forms.
**Steps.**
1. NoSQL: detect operator keys in JSON and bracket notation in forms/queries (`$ne`, `$gt`, `$gte`, `$lt`, `$lte`, `$in`, `$nin`, `$regex`, `$where`, `$or`, `$and`, `$not`, `$exists`, `$expr`, `$function`), JavaScript injection in `$where` and string contexts (`';sleep(5000);'`, `||1==1`, `this.password.match`, `return true`), and Mongo-style auth bypass (`{"username":{"$ne":null},"password":{"$ne":null}}`).
2. LDAP: filter metacharacters and structures in contexts expecting values (`*)(uid=*))(|(uid=*`, `)(|(`, `*)(objectClass=*`, `\2a` escapes), with hardness hard when parentheses and boolean operators `&|!` form a filter shape.
3. XPath: predicates and functions in value contexts (`' or '1'='1` is covered by SQL; add `//*`, `/*[1]`, `count(/*)`, `string-length(`, `substring(name(`, `text()=`, `contains(`, `] | //`), hard when XPath axes/functions are used after a breakout.
4. GraphQL injection: injection of query fragments into variable strings (`" }) { __schema`), unusual braces in `variables`, and use of aliases to brute force (counts), integrating with T-0250 metrics.
5. Define subtypes (`nosql_operator`, `nosql_js`, `ldap_filter`, `xpath`, `graphql`) and categories (`nosqli`, `ldapi`, `xpathi`) with ATK links (ATK-025 to ATK-028, ATK-056).
6. Write rule metadata, fixtures (≥ 120) and counter-examples (JSON containing `$` in legitimate keys like currency fields with field kind awareness: keys beginning with `$` are rare; allowlist for known frameworks like MongoDB drivers is not needed because operator keys from untrusted clients are exactly the attack).
7. Handle content types: JSON bodies and bracket-notation arrays in form/query (`user[$ne]=`).
8. Validate against benign corpora.
**Deliverables.**
- detectors, rules, fixtures, tests
**Acceptance.**
- A1: Mongo operator injection in JSON and bracket forms is hard.
- A2: LDAP filter breakouts are hard; ordinary parentheses in names are not.
- A3: XPath function/axis injection is hard after breakout; prose with slashes is not.
- A4: GraphQL variable injection is flagged with correct subtype.
- A5: zero false positives on benign corpora.
**Tests.**
- Table (200) / proptest / benign gate.
**Notes.** Applications using `$`-prefixed keys legitimately can add scoped exceptions (documented).
