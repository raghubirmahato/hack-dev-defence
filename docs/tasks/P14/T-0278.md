### T-0278 · SQLi core fixtures and variant generators
`P14` `[QA][SEC]` · deps: T-0254, T-0271 · size: L · owner: qa
**Objective.** Build the fixture sets that define success for the SQL injection shield.
**Steps.**
1. Create `tests/fixtures/sqli/core.txt` (Class A): the six mandated payloads at the top, then at least 300 variants generated from the evasion catalog and hand-written families: case variants, whitespace variants, comment variants, quote variants (`'`, `"`, backtick, parentheses wrappers), operand variants, URL/double URL/`%u`/HTML-entity/JSON-escape encodings, unicode lookalike quotes, wide-byte forms, and parameter-pollution splits (with files documenting how to split).
2. Create `tests/fixtures/sqli/class-b.txt` (Class B): destructive-shaped strings (`; DROP TABLE`, `xp_cmdshell`, `INTO OUTFILE`, `WAITFOR DELAY`, `SLEEP(5)`) with `.invalid` hosts, loadable only by inspect API/unit tests and the sandbox hostname.
3. Create `tests/fixtures/sqli/by-dialect/*.txt` for MySQL/MariaDB, PostgreSQL, MSSQL, Oracle, SQLite, H2/DB2-style variants (≥ 40 each).
4. Create `heldout/sqli/*` (≥ 300 entries) written independently (different phrasing styles) and excluded from rule authoring, plus a documented public-corpus import procedure with licenses (only if the operator allowlists sources; otherwise `UNVERIFIED(capability_not_supplied)` for public-corpus metrics).
5. Implement the variant generator (`xtask fixtures sqli-variants`): deterministic transformations (seeded) producing the encoding/whitespace/case/comment permutations of the mandated set, reused by proptests.
6. Create vector matrix manifests describing, per fixture, which vectors are valid (path segment, query, form field, JSON string, XML text, multipart text/filename, cookie, header) and field kinds to exercise.
7. Run the full matrix through the engine and record detection rates per family and per vector.
8. Document fixture provenance and class tagging.
**Deliverables.**
- fixture files, generators, matrix manifests, reports
**Acceptance.**
- A1: the six mandated payloads are the first entries of `core.txt` and each is `would_block` with category `sqli` in all vectors (matrix test).
- A2: core variants are 100% detected; held-out detection reported (target ≥ 95%).
- A3: Class B files are rejected by any live-capable loader (test).
- A4: dialect fixtures have at least 40 entries each.
- A5: variant generator output is deterministic for a fixed seed.
**Tests.**
- Matrix test (engine + inspect API); generator unit tests.
**Notes.** The six mandated payloads must appear exactly as supplied by the operator, including spacing.
