### T-0283 · AC-39 SQLi matrix test implementation (engine, inspect API and proxy level)
`P14` `[QA][SEC]` · deps: T-0278, T-0279, T-0261 · size: L · owner: qa
**Objective.** Implement the acceptance check that proves the core claim at every level available before the lab phase.
**Steps.**
1. Implement the matrix runner in `hdd-acceptance`: cross product of the six mandated payloads and the core variants against every vector (path, query, form, JSON, XML, multipart text, multipart filename, cookie, header) and each field kind (password, username, email, numeric id, search, free text), using the inspect API; assert `would_block=true`, category `sqli`, expected subtype, and `would_ban=true` where policy requires (except documented password H2 and cross-site cases).
2. Implement the proxy-level path: through the walking-skeleton proxy on the builder or pilot **sandbox hostname** (live) using the inspect-first gate, GET/query vectors only on `test_hostname`, body vectors only on `sandbox_hostname`; one payload at a time with unban between (until ban storage lands, rely on 60 s TTL once available), recording 403 + Ray ID + event.
3. Implement the benign suite run through the same paths: zero blocks.
4. Implement cross-site tests (`Sec-Fetch-*` headers) expecting blocks without bans once bans exist (AC-34 hooks).
5. Implement reporting: matrix tables with PASS/FAIL per cell, counts, failure details (minimal reproducers), and evidence hashes.
6. Add failure budget handling: failing cells open diagnoses.
7. Integrate with `cargo xtask acceptance --only AC-39` and record the lab-dependent portion (AC-38/AC-39 lab proof) as `UNVERIFIED(stage_not_reached)` until P16/P28.
8. Document the safety gating (Class A/B rules).
**Deliverables.**
- check implementation, reports
**Acceptance.**
- A1: matrix cells for the six mandated payloads are 100% PASS at the engine and inspect API level.
- A2: benign suite yields zero false positives in every context.
- A3: live sandbox runs respect the inspect-first gate (an altered revision fails the test).
- A4: body vectors never target `test_hostname`.
- A5: the report lists cell counts and the status taxonomy.
**Tests.**
- The matrix suite; meta-test with a deliberately disabled rule confirming failure detection.
**Notes.** Full proof with bans and a vulnerable origin completes in P16 (T-0330) and P28.
