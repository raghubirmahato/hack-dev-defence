### T-0016 · Journey maps J-01 to J-12 (acquisition to origin test)
`P01` `[DOC]` · deps: T-0012, T-0014 · size: M · owner: ux
**Objective.** Expand B3 journeys into maps with steps, user thoughts, system responses, emotions, risks and measurable success, for the acquisition and onboarding group.
**Steps.**
1. For each journey create a table: step, user action, system response, screen, data collected, error path, emotional state (calm, unsure, anxious), copy key, metric.
2. Add the "trust moments" (where the user must believe something we say) and attach the evidence we show.
3. Add the failure and recovery paths per step with exact error codes from B7 and the copy keys.
4. Add the security considerations per step (enumeration, rate limits, abuse) referencing ATK IDs.
5. Add accessibility considerations per step (focus target, announcements, keyboard).
6. Identify required screens and any missing ones; if a screen is missing, add it to B12 via a spec patch task note (do not silently invent screens).
7. Identify instrumentation (local counters) needed for the measures of T-0011.
8. Review J-08 and J-09 with extra care because they gate adoption.
**Deliverables.**
- `docs/UX/journeys/J-01.md` to `J-12.md`
**Acceptance.**
- A1: each map has at least eight steps and one failure path per step.
- A2: every step names a screen or a data-plane page.
- A3: every error path cites an ERR code that exists in B7.
- A4: security and accessibility notes exist per journey.
- A5: any proposed new screen is listed in `docs/UX/spec-patches.md`.
**Tests.**
- `xtask ux check` validates ERR codes and screen IDs.
**Notes.** The emotions column is a design aid; do not use it for tracking.
