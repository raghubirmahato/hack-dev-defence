### T-0449 · Weekly digest and executive summary generation (deterministic, honest language)
`P23` `[API][DOC]` · deps: T-0447, T-0442 · size: M · owner: data
**Objective.** Generate summaries that are accurate, calm and useful without any generative guesswork.
**Steps.**
1. Define the digest content model: headline numbers (requests, blocked, bans, appeals), notable events (top 5 by severity: SQLi on auth endpoints, possible auth bypass signals, data leak detections, campaigns), changes (rule/pack changes, mode changes, certificate renewals, DNS changes), attention items (open and new), readiness score trend, and "what we could not see" (data gaps, partial scans, unverified items).
2. Implement the **summary generator** as deterministic templates: sentence templates with parameters and pluralization via Fluent; selection logic chooses at most 7 bullet points by priority rules (documented table: severity, novelty, owner actionability); every sentence maps to a data field (traceability test).
3. Implement tone and claims rules: no fear language, no absolute claims, units and time ranges explicit ("in the last 7 days"), uncertainty stated where relevant, and every notable item linked to the relevant screen; claims-lint runs on every locale and on rendered output.
4. Implement digest preferences: frequency (off/weekly/monthly), day/time/time zone, domains included, minimum severity, and per-member subscription; unsubscribe with one click (signed token), preference center page, and suppression for inactive orgs (no traffic and no logins in 60 days → monthly cadence).
5. Implement digest rendering with the email templates catalog (HTML + text), both themes in preview, and accessible markup; links use signed deep links where appropriate.
6. Implement the "first week" special digest for new domains: explains monitor mode results, false positives to review, and the next recommended step (switching to block), generated from real data only; if the domain has no traffic, the digest says what to verify instead.
7. Implement tests: traceability (each sentence ↔ field), priority selection with ties, localization completeness, pluralization edge cases (0/1/2/5/21), claims-lint, link validation, timezone scheduling, and golden email snapshots.
8. Add the admin preview in S-120 using fixture snapshots.
**Deliverables.**
- generator, templates, preferences UI, tests
**Acceptance.**
- A1: every sentence in a generated digest is traceable to snapshot fields (automated check).
- A2: digests contain no forbidden phrases in any locale.
- A3: the "first week" digest uses only real data and says "no traffic observed" when appropriate.
- A4: unsubscribe works with one click and is idempotent.
- A5: rendering is deterministic for a given snapshot.
**Tests.**
- Unit, golden, localization checks, claims-lint.
**Notes.** No machine-generated prose: determinism and traceability are the point.
