### T-0443 · Geo and ASN analytics (S-071)
`P23` `[API][UI]` · deps: T-0441, T-0347 · size: M · owner: web
**Objective.** Show where traffic and attacks come from without overclaiming precision.
**Steps.**
1. Implement `GET D/analytics/geo` and `/asn` over rollups by `country` and `asn` with metrics (requests, blocked, block rate, bans), sort and top-N with `other`, and period comparison.
2. Build the choropleth map from a bundled simplified world topology (license verified and recorded in `design/LICENSES.md`) rendered server-side as SVG, with a ranked table that is the primary accessible representation (the map is `aria-hidden` with a text summary), a log/linear scale toggle, and patterns (not just hues) for intensity bins.
3. Implement the ASN table with organization name (from the intel DB), category (hosting, residential, mobile, education, business, unknown), and links to filtered events and the access-list creation dialog (with the self-lockout preview) for blocking an ASN.
4. Implement honesty features: a persistent note "Geolocation is approximate; VPNs, proxies and carrier NAT distort it", `Unknown` country bucket shown explicitly, database build date and source displayed, and a warning when the GeoIP database is older than 60 days.
5. Implement operator-supplied GeoIP databases (MaxMind GeoLite2 requires the operator's license key; DB-IP Lite as an alternative with attribution) loaded by `hdd-intel` with checksum verification and atomic reload; absence of a database yields the `UNVERIFIED(capability_not_supplied)` state in the UI with setup instructions (no fake data).
6. Add the "blocking a country" guard rails in the access-list dialog: warnings about collateral damage, and the self-lockout preview using the owner's current country.
7. Write tests: aggregation correctness against ground truth, `other` bucket arithmetic, DB reload under load, map rendering snapshot tests, ranking ties, a11y, and absence-of-DB behavior.
**Deliverables.**
- API, screen, intel DB loader updates, tests
**Acceptance.**
- A1: totals across countries plus `Unknown` equal the overall total exactly.
- A2: the page is fully usable through the table alone (keyboard and screen reader checks).
- A3: without a GeoIP database the page explains how to enable it and shows no invented data.
- A4: stale DB warning appears at 60+ days.
- A5: ASN block dialogs show the lockout preview.
**Tests.**
- Unit, integration, browser e2e, visual.
**Notes.** Geo data is for orientation, never for security guarantees.
