### T-0444 · Top attackers, paths, rules and categories (S-072) with pivots
`P23` `[API][UI]` · deps: T-0441, T-0445 · size: M · owner: web
**Objective.** Answer "who is attacking, what are they hitting, and what stopped them" in one place with one-click pivots.
**Steps.**
1. Implement `GET D/analytics/top/ips|paths|rules|categories|methods|user-agents` over events and rollups: top IPs (event-based within retention, honoring IP truncation), paths (templates), rules (rule ids with names for the owner), categories (matrix groups), user-agent families (hashed raw values, families only), each with counts, trends and sparklines.
2. For IPs show ban state, ban TTL remaining, reputation tags (Tor, VPN, datacenter, known scanner), ASN/country, first/last seen, distinct categories, and actions (ban/unban, allow, open ban detail S-068, view events) respecting permissions and the never-ban list.
3. Implement pivots: clicking a value applies a filter and navigates to the event explorer (T-0445) with the same period; breadcrumbs show active pivots; the URL carries state; "pin this view" saves a view.
4. Implement the **attack timeline**: stacked area chart by category over time with annotation markers for rule pack changes, mode switches and bans created in bulk, plus a table alternative.
5. Implement **campaign grouping**: events grouped by campaign (T-0325) with counts of participating IPs and ASNs; the UI says "grouped by similarity, not attribution".
6. Add the "what to do" card: contextual suggestions (e.g., "Many hits on /wp-login.php from 40 IPs: enable the WordPress preset"), derived by deterministic rules from the stats (no guesswork text), each linking to the right screen.
7. Write tests: top-N correctness (ties, truncation), pivot URL round trips, permission gating of actions, never-ban awareness, IP truncation behavior, performance (p95 ≤ 250 ms on 10M events), and a11y.
**Deliverables.**
- API, screen, suggestion rules, tests
**Acceptance.**
- A1: top lists match a naive recomputation from raw events for random periods (property test).
- A2: actions on IPs respect never-ban and org truncation settings.
- A3: pivot links reproduce the same filtered counts in the explorer.
- A4: suggestions appear only when their deterministic conditions hold (unit tests per rule).
- A5: no raw user-agent strings or full paths with query strings are displayed.
**Tests.**
- Property, integration, browser e2e.
**Notes.** The campaign label is explicitly about similarity grouping.
