### T-0171 · Domain overview page (S-043)
`P08` `[UI]` · deps: T-0168, T-0139 · size: L · owner: ui
**Objective.** Implement the domain home screen with real status and next actions.
**Steps.**
1. Implement the header: name, status pill, WAF mode pill, readiness ring and score, integration mode badge, pause banner, and quick actions menu (Add rule, Ban IP, Switch mode, View events).
2. Implement the overview tab content: requests/blocked/bans KPIs, 24-hour chart with annotations, top categories, recent events, certificate status, origin status, and the next-best-action card.
3. Implement lazy-loaded widgets with skeletons and per-widget error handling.
4. Implement the domain tab navigation (Overview, DNS, SSL/TLS, Security, Origin, Events, Bans, Analytics, Settings) with permission filtering and deep links.
5. Implement status explanations: "Waiting for DNS", "Verifying ownership", "Active", "Paused", "Suspended" with the next step.
6. Implement domain settings basics (rename display label, notes, preset switcher link, decommission link).
7. Add responsive layouts and baselines.
8. Add BOLA tests on domain-scoped routes.
**Deliverables.**
- domain header and overview, tests
**Acceptance.**
- A1: each domain status has an explanation and a next-step link.
- A2: widgets fail independently without breaking the page.
- A3: tabs deep link and preserve filters.
- A4: no fabricated metrics in empty states.
- A5: page passes axe, performance budgets and keyboard checks.
**Tests.**
- Browser per status; BOLA suite additions; performance test with 50 domains.
**Notes.** The readiness score is provided by T-0172.
