### T-0169 · Pre-cutover testing helpers: `--resolve` commands, hosts snippet, preview hostname
`P08` `[UI][API]` · deps: T-0168 · size: M · owner: api
**Objective.** Let owners test the protected path before changing public DNS.
**Steps.**
1. Generate copy-safe commands for macOS/Linux/Windows: `curl --resolve example.org:443:<HDD IP> https://example.org/` with explanatory comments, a hosts-file snippet, and PowerShell equivalent.
2. Implement the **preview hostname** `<site-id>.preview.{{PLATFORM_DOMAIN}}` served by the data plane: it routes to the site's origin with the site's Host header, uses a wildcard certificate for the preview zone, and is available only to authenticated org members via a short-lived signed token cookie or query token (to prevent open proxying), with a banner injected? (no response rewriting: instead, the preview host replies with the `HDD-Preview: 1` header and is `noindex`).
3. Rate limit and size-limit preview traffic (low caps) and exclude it from analytics unless filtered.
4. Provide "send a test request" in the UI that performs a server-side request through the full pipeline in monitor mode and shows the result (status, headers, would-block verdict) without exposing the response body beyond a small snippet.
5. Provide troubleshooting guidance for common failures.
6. Ensure the preview host cannot be used to reach other tenants' origins (token bound to site).
7. Add expiry (2 hours) and revocation.
8. Test with the pilot data plane in P11 and with unit tests now.
**Deliverables.**
- command generator, preview hostname design and control-plane pieces, UI, tests
**Acceptance.**
- A1: generated commands are syntactically valid on the three shells (parsed by a checker).
- A2: preview tokens are bound to a site and expire.
- A3: preview traffic is rate limited and flagged.
- A4: no cross-site preview access is possible (BOLA tests).
- A5: the "send a test request" feature honors the SSRF guard and size caps.
**Tests.**
- Unit: command generation; integration: token binding; live in P11 for end-to-end behavior.
**Notes.** The preview wildcard certificate comes from the platform ACME flow (T-0376).
