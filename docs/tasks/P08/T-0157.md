### T-0157 · DNS import adapters: zone file, manual entry, AXFR and provider placeholders
`P08` `[API][SEC]` · deps: T-0156 · size: L · owner: dns
**Objective.** Import existing records from the supported sources and reject the rest honestly.
**Steps.**
1. Implement the BIND zone file parser (via a vetted crate or own parser) supporting `$ORIGIN`, `$TTL`, `$INCLUDE` (disabled), multi-line parentheses, escaped characters, TXT segmentation, and relative names; limits on size (5 MiB), record count (10,000) and line length.
2. Implement the upload endpoint with strict content checks (text only), virus-like content irrelevant but size and encoding enforced; parse errors list line numbers.
3. Implement manual entry (adding records in the wizard table).
4. Implement opt-in AXFR from the owner's nameserver with optional TSIG key (stored encrypted, used once, deleted after), connecting only to NS hosts discovered for the domain and validated by the public-address policy.
5. Implement provider API adapters as a trait with no real provider shipped in Tier 1 (the trait, a contract test suite, and documentation for adding adapters); provider tokens would be stored encrypted and scoped.
6. Normalize records into the internal model, merge with scan findings, and detect conflicts and duplicates.
7. Produce the unsupported/proprietary list (ALIAS, ANAME, URL redirect, provider-specific) for the parity report.
8. Add tests with real-world style zone files including edge cases.
**Deliverables.**
- parser, import service, adapters trait, tests
**Acceptance.**
- A1: zone files with `$INCLUDE` are rejected with an explanation.
- A2: a 10,001-record file is rejected with `ERR-DNS-007`.
- A3: AXFR connects only to validated nameserver addresses and zeroizes the TSIG key afterwards.
- A4: unsupported record types appear in the import report (not silently dropped).
- A5: parsing never panics (fuzz) and handles malformed input gracefully.
**Tests.**
- Unit: parser fixture corpus (50 zone files); fuzz target; integration: AXFR against a loopback server with TSIG.
**Notes.** Provider adapters are Tier 2 work items (backlog); the trait keeps the door open.
