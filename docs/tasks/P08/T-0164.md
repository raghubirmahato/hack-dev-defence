### T-0164 · Origin connectivity test (server-side probe)
`P08` `[API][SEC]` · deps: T-0163 · size: M · owner: api
**Objective.** Let users verify the origin before going live without becoming a scanning tool.
**Steps.**
1. Implement `POST D/origin/test` creating a probe that performs: DNS resolution with the guard, TCP connect, TLS handshake (with the chosen verification mode), one HTTP request (`GET` of the health path with `Host` header and SNI as configured), no redirects, 5 s timeouts, 64 KB body cap, and the secret header if configured.
2. Return a structured result: stage-by-stage status and timing, TLS details (protocol, cipher, certificate subject/issuer/expiry/SPKI), HTTP status and selected response headers (redacted), and clear remedies for each failure class (`ERR-ORIGIN-003`, `-004`).
3. Rate limit tests (6 per minute per org, 30 per hour per site) and bound concurrency.
4. Ensure the probe cannot be used as a port scanner: only configured port, no banner reading beyond HTTP, no reflection of arbitrary response bodies (only metadata and a 200-byte escaped snippet when the response is text).
5. Record results in `origin_health` (kind: manual test) for history.
6. Implement the UI results panel with accessible status list and copyable diagnostics.
7. Implement the special case of testing before the domain is verified: allowed only for the owner with the same restrictions.
8. Add tests with real local HTTP/TLS servers with faults (slow, reset, bad cert, wrong SNI behavior).
**Deliverables.**
- probe service, UI, tests
**Acceptance.**
- A1: each failure class returns an actionable remedy.
- A2: certificate mismatch never silently downgrades.
- A3: rate limits are enforced and tested.
- A4: the probe refuses to follow redirects and prints the redirect target as information only.
- A5: response snippets are escaped and capped.
**Tests.**
- Integration with fault-injecting local servers; unit: result classification; browser: results panel.
**Notes.** The result history also feeds the readiness check "origin healthy".
