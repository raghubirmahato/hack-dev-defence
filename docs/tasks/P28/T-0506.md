### T-0506 · AC-05, AC-20, AC-22 regression and observability acceptance
`P28` `[QA][OPS]` · deps: T-0415, T-0461, T-0491 · size: M · owner: qa
**Objective.** Re-verify pass-through fidelity, IP resolution and alerting as full end-to-end checks on the latest build.
**Steps.**
1. **AC-05 (pass-through and canary):** byte-exact `static.css/js` hashes through HDD, header fidelity (`Cookie`, `Authorization` unchanged), `X-Forwarded-For` and `HDD-Connecting-IP` correctness via `echo-headers`, response header policy results, redirect pass-through, range requests, compressed responses, HTTP/2 to HTTP/1.1 translation correctness, WebSocket and gRPC passthrough smoke, large body streaming, and HEAD/304 behavior.
2. **AC-22 (IP resolution):** spoofed `X-Forwarded-For`, `Forwarded`, `X-Real-IP`, `True-Client-IP`, `CF-Connecting-IP` from the runner are ignored; the real IP is what HDD bans in lab tests; IPv6 forms; trusted-proxy configuration (when behind an upstream proxy) with the documented header trust chain; PROXY protocol handling if enabled.
3. **AC-20 (alerts and heartbeats):** cause each alert-class condition (origin down, certificate near expiry in lab with short-lived certs, DNS secondary lag, queue stuck, backup stale simulated, shield state change, mass ban, SQLi on auth endpoint, possible auth bypass) and verify the platform/tenant alert, channel delivery (fakes plus operator email if supplied), dashboard attention items, metrics and heartbeat messages; verify heartbeat absence detection.
4. **Metrics and dashboards:** check that every MET-* in the catalog exists, has the documented labels, and that the Grafana dashboards import cleanly (`xtask grafana`), and alert rules validate with `promtool`.
5. **Logging hygiene:** structured logs contain no secrets/PII beyond policy (planted canary scan), log levels, rotation.
6. **Health endpoints:** `/healthz`, `/readyz`, `/metrics` exposure restrictions (loopback/private), readiness semantics under dependency failure.
7. Record statuses and evidence; add regression entries to the non-destructive subset.
8. Feed discovered gaps into tasks under the failure budget.
**Deliverables.**
- evidence bundle, dashboards check, regression subset update
**Acceptance.**
- A1: AC-05 byte-exact and header-fidelity checks pass.
- A2: spoofed client-IP headers never influence bans or logs.
- A3: each alert condition produces the documented alert and attention item.
- A4: every cataloged metric exists with the right labels.
- A5: planted secrets never appear in logs or metrics.
**Tests.**
- Live runs, lab runs, tooling checks.
**Notes.** This is the standing non-destructive regression core (AC-00, AC-03, AC-05, AC-20, AC-22).
