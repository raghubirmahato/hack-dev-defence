### T-0149 · Platform announcements display
`P07` `[UI][API]` · deps: T-0137 · size: S · owner: ui
**Objective.** Show platform-authored banners safely.
**Steps.**
1. Implement announcement fetch for the current org/user (audience all or org-specific, active window, severity) with caching.
2. Render banners with severity styling, title and body (plain text or sanitized Markdown), optional link, dismissible state (per user, persisted) for non-critical ones.
3. Implement stacking and priority rules (critical first, max two visible, others in the notification center).
4. Implement accessibility roles (`status` for info, `alert` only for critical new items) and avoid focus stealing.
5. Implement admin authoring hooks (the announcements editor lands in P22, T-0433).
6. Implement automatic expiry and test with the clock.
7. Implement i18n for announcement bodies (per-locale variants with fallback).
8. Add visual baselines.
**Deliverables.**
- banner component, service, tests
**Acceptance.**
- A1: expired announcements disappear without reload cache issues (ETag/Vary).
- A2: critical banners cannot be dismissed; others persist dismissal.
- A3: Markdown is sanitized with the docs policy.
- A4: banners do not shift layout after load (CLS test).
- A5: locale fallback works.
**Tests.**
- Unit: priority rules; browser: dismissal persistence; sanitization fixtures.
**Notes.** Banners never include tracking links.
