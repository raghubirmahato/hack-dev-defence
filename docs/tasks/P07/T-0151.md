### T-0151 · App shell accessibility, visual and performance verification
`P07` `[QA][UI]` · deps: T-0138, T-0139, T-0141, T-0142, T-0143, T-0144, T-0145, T-0146, T-0147, T-0148, T-0149, T-0150 · size: M · owner: qa
**Objective.** Certify the P07 screens against the UI definition of done.
**Steps.**
1. Run the full suite on S-040, S-075, S-084, S-085, S-086, S-091 and the frame in both themes and the viewport matrix: axe, keyboard traversal, reflow, spacing, forced colors, reduced motion, target size.
2. Run visual regression with baselines for empty and populated states.
3. Run performance budgets for the overview and audit pages with seeded data.
4. Run the empty-database sweep and the honest-data checks.
5. Run the permission-filtered navigation matrix across roles.
6. Run the pseudo-locale overflow check.
7. Fix findings, update baselines with reasons, and record accepted minor issues.
8. Produce the summary for the gate report.
**Deliverables.**
- reports in `acceptance-ui/`, baseline updates
**Acceptance.**
- A1: zero serious/critical axe findings.
- A2: budgets pass.
- A3: honest-data sweep passes.
- A4: role-based navigation matrix passes.
- A5: pseudo-locale shows no clipping.
**Tests.**
- The suites named above.
**Notes.** These checks become part of `cargo xtask ui verify` permanently.

## Definition of done for this task's tags (section 0.7)

### `[QA]`: Test infrastructure

Real services only (no mocks); deterministic or seeded; evidence output stored under git-ignored `acceptance-*/` with sha256.

### `[UI]`: Renders HTML to a human

Server-side escaped output only; empty, loading, error, offline and permission-denied states implemented honestly (no fake data); keyboard-only operation verified; focus order and visible focus; WCAG 2.2 AA via the axe oracle with zero serious or critical findings; contrast tokens only (no ad-hoc colors); responsive screenshots at 360, 768, 1280 px in dark and light; i18n keys only (no literal user-facing strings in templates); CSP clean (no inline script or style, no console errors); size budgets (E4) respected; visual-regression baseline updated with reviewer note.
