### T-0599 · Acceptance AC-59 to AC-62, coverage-map update and gate G34
`P34` `[QA][DOC][OPS]` · deps: T-0585, T-0587, T-0592, T-0593, T-0595, T-0596, T-0597, T-0598, T-0578 · size: L · owner: qa
**Objective.** Prove the phase and publish honest numbers.
**Steps.**
1. Implement AC-59: Sentinel safety and robustness (shadow no-effect differential, no-ban-alone matrix, fail-safe chaos, poisoning and extraction campaigns, prompt-injection suite, the published unseen-family numbers).
2. Implement AC-60: Bypass Guard (signed-authentication matrix across servers, tunnel with closed inbound, firewall generator checks, continuous verification with injected bypasses, the go-live gate and protected-state contract).
3. Implement AC-61: known-vulnerability coverage (VKB import and matching, pipeline lint and false-positive gate, emergency channel, ATK-301 to ATK-390 matrix with lab proofs and `shape-only` labels).
4. Implement AC-62: additional hardening (parser-differential matrix, padded and split payloads, cache guard, honeytokens, integrity watch, AI-endpoint protections).
5. Regenerate the coverage map with the new rows (OWASP LLM Top 10 added), run the completeness audit, and downgrade any row without evidence.
6. Run the full regression (AC-06 false-positive baseline, AC-39 matrix) with Sentinel in `shadow`, then `assist` and `block` on the lab site, to prove no loss of detection and no new false positives.
7. Update the final-report template (T-0540) and the claims audit with the new claim families.
8. Close gate G34 with the report in the E5.1 format.
**Deliverables.**
- AC-59 to AC-62 implementations, updated coverage map, regression results, gate report
**Acceptance.**
- A1: AC-59 to AC-62 each end PASS or UNVERIFIED with enumerated reasons; none ends FAIL.
- A2: with Sentinel in every mode the AC-06 false-positive baseline stays at zero and AC-39 detection does not drop.
- A3: the coverage-map audit reports counts and no covered row without evidence.
- A4: claims-lint passes on every new surface and finds no statement that bypass is impossible or that attacks cannot succeed.
- A5: the published Sentinel and Bypass Guard numbers name their manifests and verification dates.
**Tests.**
- The AC suites; regression runs; claims audit.
**Notes.** A downgraded coverage row is a success of the audit.
