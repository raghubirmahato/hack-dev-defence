### T-0552 · Tier 4: OpenTelemetry tracing and metrics export
`P32` `[OPS][DP]` · deps: T-0214, T-0372 · size: M · owner: ops
**Objective.** Let operators plug HDD into their observability stack with standard telemetry, safely.
**Steps.**
1. Implement OTLP export (gRPC and HTTP/protobuf) for traces and metrics from all services via the `opentelemetry` crates, configurable endpoint (egress allowlist), TLS/mTLS, headers (auth tokens stored encrypted), batch settings, resource attributes (service, version, node), and sampling (parent-based, ratio default 1% for the proxy hot path, 100% for control plane errors).
2. Keep the existing span structure: request spans with Ray ID, stage timings and decisions; **privacy rules:** no request bodies, no cookies, no query strings, IP per truncation settings, path templates only; attribute allowlist enforced centrally; PII scrubber tests.
3. Ensure **hot-path safety:** export on a separate bounded queue and thread/task, drop on overflow with a counter, no blocking; measure overhead (≤ 2% CPU at 1% sampling).
4. Implement trace context propagation to origins (`traceparent`) as an opt-in per site (default off to avoid fingerprinting/leaks) and acceptance of inbound `traceparent` with sanitation (accepted only from trusted sources; otherwise new trace).
5. Provide exemplar linking from latency histograms to traces (Ray ID) for Prometheus users.
6. Provide dashboards/documentation for Grafana Tempo/Jaeger/Honeycomb-style backends (docs only; tested against Tempo/Jaeger containers in the lab).
7. Write tests: attribute allowlist (fuzz), queue overflow behavior, sampling correctness, trace propagation rules, exporter failure isolation.
8. Update docs and metrics catalogs.
**Deliverables.**
- OTLP exporters, privacy filters, docs, tests
**Acceptance.**
- A1: no forbidden attribute appears in any exported span (fuzzed attribute test).
- A2: exporter outages do not affect request latency (chaos test).
- A3: sampling ratios hold within tolerance.
- A4: propagation defaults are off and sanitized when on.
- A5: overhead target met.
**Tests.**
- Unit, fuzz, lab integration with Tempo/Jaeger, performance.
**Notes.** Metrics remain exposed via Prometheus as the default path.
