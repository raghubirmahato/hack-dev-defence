### T-0383 · Origin mutual TLS (client certificates) option
`P19` `[DP][SEC]` · deps: T-0365, T-0195 · size: M · owner: sec
**Objective.** Offer a stronger origin lockdown than a shared secret header.
**Steps.**
1. Implement per-site (or per-org) client certificate generation by the internal PKI: ECDSA P-256 keys generated by HDD, certificate with long-ish lifetime (90 days) and automatic rotation 30 days before expiry, subject identifying the site, private key stored via envelope encryption.
2. Implement the connector support: present the client certificate during origin handshake when `origin_mtls` is enabled; handle rotation with overlap (origin must trust the CA; provide CA certificate download for the owner to configure on their web server).
3. Implement owner UX in the lockdown wizard (T-0406): enable mTLS, download the issuing CA PEM, snippets for nginx (`ssl_client_certificate`, `ssl_verify_client on`), Apache (`SSLVerifyClient require`), HAProxy/Caddy equivalents, and a verification probe (HDD connects with and without cert and compares origin behavior).
4. Implement rotation notifications and failure alerts (origin rejects cert).
5. Implement revocation (rotate on suspected compromise) and CRL not required (short life + rotation).
6. Test with local origins requiring client certificates.
7. Document security properties (stronger than header secrets; origin config required).
8. Ensure private keys never leave the platform except to the proxy memory.
**Deliverables.**
- mTLS support, UI integration hooks, tests, docs
**Acceptance.**
- A1: an origin requiring client certs accepts HDD and rejects others (test).
- A2: rotation with overlap causes no downtime.
- A3: private keys never appear in API responses or logs.
- A4: snippets for the four servers are syntactically validated in CI where possible.
- A5: verification probe distinguishes configured and unconfigured origins.
**Tests.**
- Integration with TLS test servers; unit: rotation scheduling.
**Notes.** The secret header remains the default for simplicity.
