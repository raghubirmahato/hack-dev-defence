### T-0385 · TLS end-to-end acceptance (AC-04) including DNS-01 wildcard and production rehearsal
`P19` `[QA][DP]` · deps: T-0377, T-0378, T-0379, T-0380, T-0381 · size: L · owner: qa
**Objective.** Prove real certificate operations on the pilot using the staging CA, and rehearse production issuance safely.
**Steps.**
1. Execute AC-04 fully on the pilot: HTTP-01 for `test_hostname`, DNS-01 wildcard for the pilot zone (authoritative TXT served by HDD), CNAME-delegated `_acme-challenge` case for a partial-mode test name (UNVERIFIED `human_step_pending` until the operator adds the CNAME), forced short-window renewal, CT entry observation (staging), TLS posture oracle checks, unknown/absent SNI refusal, HSTS/redirect checks.
2. Rehearse the **production issuance procedure** on staging end to end (budget checks, approval flag, issuance, verification against a public trust store simulation using the staging root), and write the exact production runbook steps for the operator, including the approval message the agent will ask for.
3. Verify budgets: ensure the staging run stays within conservative counts; record the CA limit configuration provenance.
4. Verify certificate hot reload on live traffic with a long-lived connection test.
5. Verify rollback: delete the issued staging certificate and confirm alerting and re-issuance.
6. Record all evidence with SHA-256 and update the AC-04 status line.
7. Draft the operator approval request for the one-time production issuance (to be sent at T-0538).
8. Fix failures under R-14.
**Deliverables.**
- AC-04 evidence, production runbook, approval request draft
**Acceptance.**
- A1: AC-04 staging checks PASS (or UNVERIFIED with reasons only for human-step or capability gaps).
- A2: forced renewal on staging succeeds and the proxy serves the new certificate within 2 s.
- A3: the production runbook is complete and rehearsed without contacting the production CA.
- A4: no production issuance occurred (audit log confirms `acme_production_enabled=false`).
- A5: evidence is archived with hashes.
**Tests.**
- Live runs from the runner.
**Notes.** Production issuance is one event with approval (section 4/R-04).
