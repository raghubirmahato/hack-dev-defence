# J-12 Owner configures and tests the origin

Personas: [Maya](../personas/maya.md), [Dan](../personas/dan.md). Emotional state is a design aid, not a measured value.

Trigger: the domain resolves to HDD but the origin that serves it still has to be configured and tested.

## Security considerations

| Step | Risk | Control | ATK |
| --- | --- | --- | --- |
| 2 | SSRF to loopback or private ranges. | The egress path checks the resolved address against the SSRF guard (ERR-ORIGIN-001). | ATK-091 |
| 2 | SSRF to a cloud metadata endpoint. | The guard rejects link-local metadata addresses and resolves before connecting. | ATK-092 |
| 4 | Host-header injection changes the request target. | The Host header is validated and the redacted result shows what was sent. | ATK-057 |
| 6 | Plaintext origin is accepted silently. | Plaintext needs the acknowledged mode, and the result shows the mode used. | ATK-072 |
