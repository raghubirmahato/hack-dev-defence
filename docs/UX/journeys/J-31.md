# J-31 Platform admin toggles safe mode, maintenance, checks infra

Personas: [Omar](../personas/omar.md). Emotional state is a design aid, not a measured value.

Trigger: a deployment window starts and the platform admin must set maintenance mode, watch the infrastructure and be ready to use the emergency controls.

## Admin controls

| Action | Permission | Audit event | Reason required | Step-up |
| --- | --- | --- | --- | --- |
| Read infrastructure health | PERM-platform.infra.read | No B8 event records an infrastructure read | no | no |
| Enable platform safe mode | PERM-platform.emergency | AUD-platform.emergency_used | typed | yes |
| Set maintenance mode | PERM-platform.flags.write | AUD-platform.flag_changed, and B8 lists maintenance in the same row | yes | yes |
| Clear an emergency control | PERM-platform.emergency | AUD-platform.emergency_cleared | typed | yes |

B8 groups the flag and maintenance changes in the row `AUD-platform.flag_changed / maintenance_changed`.
The maintenance cell keeps the first id of that row and names the grouping instead of inventing an id;
T-0433 and T-0434 resolve the exact event name when the event is implemented.

## Stress cases

| Case | What changes | What stays usable |
| --- | --- | --- |
| low bandwidth | The node table loads before the sparkline charts. | The state text and the control actions stay usable. |
| small screen | The service table becomes a list of cards. | Every row action stays in the tab order. |
| keyboard only | The emergency controls open from the keyboard. | Enter confirms the typed dialog and Escape cancels it. |

## Instrumentation

- `AUD-platform.emergency_used` records an emergency control with its expiry.
- `AUD-platform.emergency_cleared` records the clear and the actor.
- `AUD-platform.flag_changed` records a feature flag or maintenance change.

## Success and checks

Success: the maintenance window is announced, safe mode is time boxed, the hosting check explains each failed requirement and every control is audited. Checks: AC-13, AC-42.
