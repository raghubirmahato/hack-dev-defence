# J-08 Owner adds a domain using full nameserver delegation

Personas: [Maya](../personas/maya.md), [Alex](../personas/alex.md). Emotional state is a design aid, not a measured value.

Trigger: the owner has a domain at a registrar and wants HDD to proxy it with full nameserver delegation.

## Cutover safety

| Step | What could break the live site | Guard | Undo |
| --- | --- | --- | --- |
| 2 | A scan that runs against the wrong zone could hide records. | The preview and the zone scan run before any change is offered. | Undo by keeping the provider; the R-19 return path stays open. |
| 3 | The nameserver change removes the existing delegation. | The parity check lists every imported record before the nameserver choice. | Undo with the instant return path of R-19 and the old nameservers. |
| 4 | A proxied mail record stops mail delivery. | The preview marks mail records grey before the proxy toggle is saved. | Undo with rollback to the previous zone snapshot. |
| 5 | A wrong TXT record blocks ownership without touching traffic. | The verification TXT preview shows the exact record before the change. | Undo by deleting the TXT record; no traffic moves. |
| 7 | A DNS challenge record leaks the pre-issuance plan to the wrong zone. | The TLS plan preview lists the challenge records before any DNS change. | Undo by removing the challenge records; no traffic moves. |
| 12 | The final proxy state is wrong after activation. | The activation checklist and the proxy preview run before the final cutover. | Undo with the R-19 return path and the previous proxy state. |
| 9 | The delegation is switched while the checklist is unfinished. | The go-live checklist and the propagation poll precede the cutover. | Undo with the instant return path of R-19 and the rollback instructions. |
| 11 | Propagation is assumed before every resolver agrees. | The propagation check uses the resolver matrix before go-live. | Undo with the previous nameservers and the TTL-based rollback. |

## Instrumentation

- `AUD-dns.parity_acknowledged` and `AUD-waf.mode_changed` supply the parity and preset counters.
- Time to first domain in monitor mode uses the domain audit times; B8 has no domain event.
- Completion rate of the add-domain wizard reads the stored wizard step.
