# J-01 Visitor discovers HDD and reads honest claims

Persona: [Maya](../personas/maya.md). Emotional state is a design aid, not a measured value.

Trigger: a search result or a referral. The visitor has not used the product before and is deciding whether to trust it.

| Step | User action | System response | Screen | Data collected | Error path | Emotional state | Copy key | Metric |

## Instrumentation

- `AUD-auth.signup` is the audit source for the counter of visitors who create an account from this journey.
- A local counter of public page requests (`public_page_requests_total`) reads the request log and stores no visitor id.
- The support-worthy error counter reads `ERR-PERM-002` and `ERR-SYS-*` from the error log, as defined in MEASURES.md.

## Success and checks

Success: the visitor reaches S-020 in three clicks or fewer, the page weight stays within budget, and no tracking cookie is set. Checks: AC-40, AC-41, claims-lint.
