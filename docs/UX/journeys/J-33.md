# J-33 User exports data or deletes the account

Personas: [Maya](../personas/maya.md), [Alex](../personas/alex.md), [Dan](../personas/dan.md). Emotional state is a design aid, not a measured value.

Trigger: the user wants a copy of their data or wants to leave the product for good.

## Steps

| Step | User action | System response | Screen | Data collected | Error path | Emotional state | Copy key | Metric |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | Opens the data and privacy page. | The page checks the account self permission before it renders. | S-090 | none | ERR-PERM-001: The privacy page is refused and the account self permission is named. | calm | privacy-title | Privacy page visits per month |
| 2 | Requests a data export. | The export request is rate limited per account. | S-090 | none | ERR-RATE-001: The export request is throttled by the rate limit and the reset time appears. | unsure | privacy-export-request | Data exports requested per month |
| 3 | Confirms the export with re-authentication. | The export asks for re-authentication before the request starts. | S-032 | none | ERR-AUTH-008: Re-authentication is required before the export starts, and the step-up page opens. | calm | privacy-export-stepup | - |
| 4 | Opens the emailed export link. | The export link is checked before it expires. | email | none | ERR-AUTH-009: The export link has expired, so a resend is offered. | unsure | privacy-export-link | - |
| 5 | Returns to the privacy page and requests deletion. | The deletion states the owner transfer prerequisite for the organization. | S-090 | none | ERR-ORG-004: The deletion states the owner transfer prerequisite, so the last owner stays. | anxious | privacy-deletion-request | Deletion requests per month |
| 6 | Reads the grace period and cancels the deletion by mistake. | The page changed after the deletion request, so it reloads the current state. | S-090 | none | ERR-CONC-001: The deletion request changed, so reload and retry with the current state. | anxious | privacy-deletion-cancel | - |
| 7 | Confirms the deletion after the grace period. | The request asks for re-authentication before the deletion saves. | S-090 | none | ERR-AUTH-008: The deletion request asks for re-authentication before it saves. | anxious | privacy-deletion-confirm | - |
| 8 | Signs out and waits for the deletion receipt. | The receipt request reports an unexpected error and a request id is shown. | email | none | System error ERR-SYS-002: The receipt request reports an unexpected error and a request id is shown. | anxious | privacy-deletion-receipt | - |

## Trust moments

| Step | What the user must believe | Evidence we show |
| --- | --- | --- |
| 2 | The export contains my data and nothing else. | The request names the scope, the format and the delivery address. |
| 5 | Deletion is reversible for a while. | The page states the grace period and the cancel action before the request is saved. |

## Security considerations

| Step | Risk | Control | ATK |
| --- | --- | --- | --- |
| 3 | An export link is opened on a shared device. | The export needs re-authentication and the link is single use. | ATK-161 |
| 5 | A member deletes an organisation owned by someone else. | The owner transfer prerequisite is checked and the deletion needs the owner role. | ATK-172 |
| 8 | The deletion receipt leaks another account's status. | The receipt is identical for every request and never names another account. | ATK-295 |

## Safeguards

| Step | Risky action | Safeguard | Kind | Copy key | Exact copy |
| --- | --- | --- | --- | --- | --- |
| 2 | Requesting a data export. | The request states the scope, the format and the delivery address first. | preview | privacy-export-preview | Check the scope, the format and the delivery address before you request; the export is delivered once. |

## What could go wrong

| Step | What goes wrong | Recovery action |
| --- | --- | --- |
| 4 | The export link expires on a slow connection. | The page offers a resend and keeps the request status visible. |
| 5 | The only owner requests deletion. | The owner transfer prerequisite is named and the request is refused until a new owner is set. |
| 7 | The deletion runs while the user is still deciding. | The grace period is configurable and the cancel action stays visible for its whole length. |

## Timelines

The export and the deletion are configurable defaults; the page states the value that this deployment uses and links to the policy page.

| Request | Timeline | User sees |
| --- | --- | --- |
| Data export | Within 24 hours by default, configurable up to 7 days. | The page states the request time and the delivery address. |
| Data deletion | After a grace period of 30 days by default, configurable. | The page states the grace period and the cancel action. |

## Stress cases

| Case | What changes | What stays usable |
| --- | --- | --- |
| low bandwidth | The sections render as plain text before the confirmation dialogs. | The export and deletion actions stay usable. |
| small screen | The sections stack and the dialogs fill the viewport. | The cancel and confirm actions stay in the tab order. |
| keyboard only | The dialogs and the typed confirmation work without a pointer. | Tab reaches the request, the cancel and the confirm actions. |

## Instrumentation

- `AUD-auth.data_export_requested` records an export request with its scope and range.
- `AUD-org.deleted` records the deletion of an organisation that the user owned.

## Success and checks

Success: the export arrives with the stated scope and the deletion can be cancelled during the configurable grace period. Checks: AC-47.
