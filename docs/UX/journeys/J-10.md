# J-10 Owner attaches an apex via A/ALIAS or only a subdomain

Personas: [Maya](../personas/maya.md), [Dan](../personas/dan.md). Emotional state is a design aid, not a measured value.

Trigger: the owner wants the apex (`example.org`) to reach HDD, and a CNAME cannot sit at the apex.

## Steps

| Step | User action | System response | Screen | Data collected | Error path | Emotional state | Copy key | Metric |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | Reads why a CNAME cannot sit at the apex. | The explanation names the alternatives without dismissing the current provider. | S-042 | none | ERR-DNS-002: The explanation says a CNAME cannot sit at the apex because the apex already holds other data, so a conflicting record is refused. | unsure | apex-explanation-title | Completion rate of the add-domain wizard |
| 2 | Chooses A records to the HDD addresses. | The wizard lists the addresses and warns about keeping them current. | S-042 | none | ERR-SYS-001: The system keeps the A-record guidance visible while the addresses list is temporarily unavailable. | unsure | apex-a-records | - |
| 3 | Chooses ALIAS/ANAME where the provider supports it. | The wizard names the edge target and marks the option as provider-dependent. | S-042 | none | ERR-SYS-001: The system keeps the ALIAS guidance visible while the provider lookup is temporarily unavailable. | calm | apex-alias-option | - |
| 4 | Reads the warning that A-record mode needs current addresses. | The warning states that HDD announces address changes 30 days in advance. | S-042 | none | ERR-SYS-003: The system shows the maintenance notice instead of the operator address list. | unsure | apex-address-notice | - |
| 5 | Copies the A records and checks propagation. | The resolver matrix shows the apex result and the time per resolver. | S-099 | none | ERR-DOM-007: The propagation matrix says delegation is not detected at some resolver yet. | anxious | apex-propagation-title | - |
| 6 | Reads the rollback warning before saving. | The page shows how to return the apex to the provider values. | S-042 | none | ERR-SYS-001: The system keeps the rollback warning visible while the checklist is unavailable. | calm | apex-rollback-note | - |
| 7 | Confirms the apex attachment. | The wizard saves the mode and states which records it will manage. | S-042 | none | ERR-DOM-005: The page says the domain is not in a state that allows the record change yet. | unsure | apex-confirm-title | - |
| 8 | Checks the domain overview. | The overview shows the apex state and the next action. | S-043 | none | ERR-SYS-001: The system shows the apex as pending while the overview is unavailable. | calm | apex-overview-title | - |

## Trust moments

| Step | What the user must believe | Evidence we show |
| --- | --- | --- |
| 1 | The limitation is real and the alternatives are honest. | The page names the CNAME/apex rule and every alternative in one place. |
| 4 | HDD will warn before an address change matters. | The 30-day notice statement appears before the address is copied. |

## Security considerations

| Step | Risk | Control | ATK |
| --- | --- | --- | --- |

## Instrumentation

- `AUD-dns.parity_acknowledged` supplies the counter for the record review, and `AUD-waf.mode_changed` covers the mode change.
- B8 has no apex-specific event; the gap is stated here rather than invented.

## Success and checks

Success: the apex reaches HDD by A/ALIAS records, or only the subdomain is proxied. Checks: AC-37.
