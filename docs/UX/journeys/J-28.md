# J-28 Owner exports reports and audit logs

Personas: [Dan](../personas/dan.md), [Sara](../personas/sara.md), [Alex](../personas/alex.md), [Omar](../personas/omar.md). Emotional state is a design aid, not a measured value.

Trigger: a client asks for a monthly report and an auditor asks for the audit evidence behind it.

## Steps

| Step | User action | System response | Screen | Data collected | Error path | Emotional state | Copy key | Metric |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | Opens reports and picks a template. | The template asks for the report parameters. | S-073 | none | ERR-REPORT-001: The report template parameters are invalid and the wrong field is named. | calm | report-template | Reports generated per org per month |
| 2 | Builds the report for a period and domains. | The date range value is checked against the allowed range. | S-074 | period, domains | ERR-VAL-005: The date range value is outside the allowed range and the limits are shown. | unsure | report-build | - |
| 3 | Previews the report. | The preview service renders the sections with their data windows. | S-074 | none | System error ERR-SYS-001: The preview service is temporarily unavailable and the last preview stays on screen. | unsure | report-preview | - |
| 4 | Schedules the report to the recipients. | The report quota is checked before the schedule saves. | S-074 | recipients, schedule | ERR-RATE-002: The report quota is exceeded and the plan quota link appears. | calm | report-schedule | - |
| 5 | Runs the report now and waits for the run. | The run request carries an idempotency key. | S-073 | none | ERR-IDEMP-001: The run request reuses an idempotency key and the existing run is returned. | calm | report-run | - |

## Trust moments

| Step | What the user must believe | Evidence we show |
| --- | --- | --- |
| 2 | The report covers the period it says it covers. | The preview names the data window and the time zone of each section. |
| 8 | The audit export is the evidence, not a summary. | The page shows the chain verification result before the download starts. |

## Security considerations

| Step | Risk | Control | ATK |
| --- | --- | --- | --- |
| 4 | A scheduled report reaches the wrong recipients. | The recipient list needs a confirmation and the schedule records who added each address. | ATK-276 |
| 6 | A download link is shared outside the organisation. | The link is single use, expires quickly and each download is audited. | ATK-164 |
| 8 | An audit export leaks personal data. | The export is permission checked, redacted by policy and audited. | ATK-173 |

## What could go wrong

| Step | What goes wrong | Recovery action |
| --- | --- | --- |
| 3 | The preview shows a section without data. | The section states Unknown and the reason instead of a fabricated value. |
| 5 | The run is started twice. | The idempotency key returns the existing run instead of a duplicate. |
| 8 | The audit chain verification fails. | The page stops the export and shows the failing link and the request ID. |

## Stress cases

| Case | What changes | What stays usable |
| --- | --- | --- |
| low bandwidth | The charts render as tables first and the preview images are skipped. | The parameters, the run state and the download stay usable. |
| small screen | The builder stacks its fields and the chart tables scroll inside their region. | Every field and the run action stay in the tab order. |
| keyboard only | The date pickers accept typed values. | Tab reaches the preview, the schedule and the export. |

## Instrumentation

- `AUD-report.run` records a report run with the period and the row count.
- `AUD-report.downloaded` records each download with the actor.
- `AUD-export.audit` records an audit export with the range and the row count.

## Success and checks

Success: the report is generated for the stated period, the audit export verifies its hash chain and both actions appear in the audit log. Checks: AC-47.
