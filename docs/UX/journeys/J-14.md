# J-14 Owner edits DNS and toggles orange/grey

Personas: [Maya](../personas/maya.md), [Dan](../personas/dan.md). Emotional state is a design aid, not a measured value.

Trigger: the owner changes a record or a proxy state after the zone is active

## Steps

| Step | User action | System response | Screen | Data collected | Error path | Emotional state | Copy key | Metric |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | Reads the DNS record table. | The table lists type, name, value and proxy state. | S-045 | none | System error ERR-SYS-001: The record table is temporarily unavailable; reload the page. | calm | dns-records-title | - |
| 2 | Opens a record for inline edit. | The editor opens with the type-specific fields. | S-046 | none | ERR-DNS-001: The editor says the record is not valid for this type and shows the fields. | unsure | dns-record-edit | - |
| 3 | Changes the record value after the preview. | The preview shows what will resolve before the save. | S-046 | record value | ERR-DNS-005: The page says the change would remove records required for the domain and shows them. | unsure | dns-record-save | - |
| 4 | Toggles the proxy state after the consequence text. | The page states what proxying changes and keeps mail records grey. | S-046 | proxy state | ERR-DNS-004: The toggle keeps a mail record grey because mail records cannot be proxied. | anxious | dns-proxy-toggle | - |
| 5 | Reads the change history. | The history lists each change with its time and the previous value. | S-048 | none | System error ERR-SYS-001: The change history service is temporarily unavailable; the entry stays listed. | calm | dns-history-title | - |
| 6 | Returns to the record table from the history. | The table reflects the saved change. | S-045 | none | ERR-DNS-002: The record shown as conflicting keeps its value, and the table reloads the saved state. | calm | dns-back-to-records | - |
| 7 | Opens the history entry for the changed record. | The entry shows the before and after values. | S-048 | none | System error ERR-SYS-001: The history entry service is temporarily unavailable; values stay listed. | calm | dns-history-entry | - |
| 8 | Reads the resolved-value preview. | The preview states which record answers a query. | S-046 | none | ERR-DNS-003: Only A, AAAA and CNAME records can be proxied, so the preview marks this record type grey. | calm | dns-resolve-preview | - |

## Trust moments

| Step | What the user must believe | Evidence we show |
| --- | --- | --- |
| 1 | The table is the zone, not a cache. | The header names the zone and the refresh time. |
| 3 | The preview is what will resolve. | The preview is server-rendered from the same record the save uses. |

## Safeguards

| Step | Risky action | Safeguard | Kind | Copy key | Exact copy |
| --- | --- | --- | --- | --- | --- |
| 3 | Changing a record value. | The preview shows the resolved value before the save. | preview | dns-record-preview | Review the record before you save; the previous value stays in the change history. |
| 4 | Toggling the proxy state. | The consequence text is shown before the toggle applies. | confirmation | dns-proxy-confirm | Read what proxying changes; you can toggle it back from the record row. |

## What could go wrong

| Step | What goes wrong | Recovery action |
| --- | --- | --- |
| 1 | The table shows a stale record. | The refresh time is shown and the table can be reloaded. |
| 3 | The change removes a required record. | The save is refused and the required records are named. |
| 4 | A mail record is proxied. | Mail records stay grey and the preview explains why. |

## Instrumentation

- `AUD-dns.parity_acknowledged` supplies the counter for the change acknowledgement.

## Success and checks

Success: the record or proxy state changes and the preview matches the result. Checks: AC-03.
