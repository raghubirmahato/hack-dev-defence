# J-11 Owner verifies ownership

Personas: [Maya](../personas/maya.md), [Dan](../personas/dan.md), [Alex](../personas/alex.md). Emotional state is a design aid, not a measured value.

Trigger: the wizard asks the owner to prove control of the domain before HDD touches its traffic.

## Steps

| Step | User action | System response | Screen | Data collected | Error path | Emotional state | Copy key | Metric |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | Reads the two verification methods. | The page shows the DNS TXT and HTTP file methods side by side. | S-042 | none | ERR-DOM-004: The wizard says ownership has not been verified and shows both methods again. | unsure | verification-methods-title | Completion rate of the add-domain wizard |
| 2 | Copies the TXT record into the provider. | The page keeps the exact name and value with copy buttons. | S-042 | TXT record | ERR-DNS-002: The page says a conflicting record blocks the TXT record and names the wildcard. | unsure | verification-txt-copy | - |
| 3 | Copies the HTTP file to the site. | The page serves the exact content to fetch and states the path. | S-042 | file content | ERR-DOM-004: Ownership is not verified because the HTTP file is missing at the expected path; the exact path and content are shown again. | unsure | verification-http-file | - |
| 4 | Watches the verification poller with timestamps. | The poller lists each attempt with its time and result. | S-042 | none | ERR-DOM-004: The poller says ownership has not been verified yet and shows the last check time. | anxious | verification-poller-title | - |
| 5 | Waits for the automatic re-verification. | The page states the re-check schedule and keeps the last result visible. | S-099 | none | ERR-SYS-001: The system keeps the verification schedule visible while the poller is unavailable. | calm | verification-recheck-note | - |
| 6 | Retries after a CDN caches the HTTP file. | The page suggests the TXT method and explains the cache behaviour. | S-042 | none | ERR-DOM-004: Ownership is not verified because a CDN may be serving a cached copy of the HTTP file; the TXT method is offered instead. | unsure | verification-cdn-note | - |
| 7 | Resolves a wildcard TXT conflict. | The page names the conflicting wildcard record and the exact expected value. | S-042 | TXT record | ERR-DNS-002: The page says a conflicting record from the wildcard blocks the TXT value. | unsure | verification-wildcard-note | - |
| 8 | Confirms the domain is verified. | The overview shows the verified state and the next step. | S-043 | none | ERR-SYS-001: The system shows the domain as verified while the overview is unavailable. | calm | verification-success-title | - |

## Trust moments

| Step | What the user must believe | Evidence we show |
| --- | --- | --- |
| 1 | Either method is enough, and neither leaks a secret. | The two methods are listed together with the exact value for each. |
| 4 | The check is real and the timestamp is honest. | Each poll attempt carries a server-side timestamp and result. |

## Security considerations

| Step | Risk | Control | ATK |
| --- | --- | --- | --- |
| 1 | A forged ownership claim takes another owner's domain. | The token is unique per domain and expires; a bad token answers ERR-DOM-004. | ATK-161 |
| 3 | A host-header trick serves the file to the verifier from another host. | The verifier requests the exact host and path and never follows a redirect to another host. | ATK-152 |
| 7 | A wildcard TXT record shadows the expected value. | The verifier reports the conflict instead of accepting a wildcard match. | ATK-225 |
