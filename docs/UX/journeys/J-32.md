# J-32 Owner removes a domain safely

Personas: [Maya](../personas/maya.md), [Alex](../personas/alex.md). Emotional state is a design aid, not a measured value.

Trigger: the owner is leaving for another provider and must return DNS without leaving dangling records behind.

## Steps

| Step | User action | System response | Screen | Data collected | Error path | Emotional state | Copy key | Metric |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | Opens the decommission wizard from the domain settings. | The wizard lists the current integration mode and the records HDD serves. | S-094 | none | ERR-DOM-005: The domain is not in a state that allows decommission, and the current state is shown. | anxious | decommission-title | Domains decommissioned per month |
| 2 | Chooses the desired end state: return DNS to the previous provider. | The page checks the domain delete permission and explains the change at the registrar. | S-094 | end state | ERR-PERM-001: The decommission is refused and the missing domain delete permission is named. | unsure | decommission-end-state | - |
| 3 | Exports the current zone as a backup. | The export lists every record with its type and TTL. | S-048 | none | ERR-DNS-007: The zone size limit is reached and the export is refused. | calm | decommission-export | - |
| 4 | Reviews the exact record changes that revert the DNS. | The diff shows the records to recreate at the previous provider. | S-047 | none | ERR-DNS-005: The change would remove records required for the domain to work, and they are named. | anxious | decommission-revert-diff | - |
| 5 | Revokes the HDD certificates after the confirmation. | The certificate list shows the revoke time and the reason. | S-051 | none | System error ERR-ACME-006: The certificate authority is unreachable, so the revocation is retried with backoff and the next attempt time is shown. | anxious | decommission-revoke-certs | - |
| 6 | Confirms the removal by typing the domain name. | The confirmation asks for re-authentication before the removal saves. | S-094 | domain name | ERR-AUTH-008: Re-authentication is required before the removal, and the step-up prompt opens. | anxious | decommission-confirm | - |
| 7 | Makes the DNS change at the registrar. | The wizard shows the old and new nameservers with the revert text. | S-094 | none | ERR-DOM-007: Delegation is not detected yet and the observed nameservers are shown. | anxious | decommission-registrar | - |
| 8 | Confirms the domain is removed and checks for dangling references. | The report service lists dangling records and the completion time. | S-094 | none | System error ERR-SYS-001: The report service is temporarily unavailable and the last report stays visible. | calm | decommission-report | Domains left with dangling records |

## What could go wrong

| Step | What goes wrong | Recovery action |
| --- | --- | --- |
| 3 | The zone export is missing a record. | The export names every record and the parity report compares it with the previous zone. |
| 5 | A certificate is still used by another domain. | The certificate list names the covered names before the revoke. |
| 7 | The registrar keeps the old delegation. | The poller reports the observed nameservers and the next check time. |

## Stress cases

| Case | What changes | What stays usable |
| --- | --- | --- |
| low bandwidth | The record diff loads as text before the coloured diff. | The export and the typed confirmation stay usable. |
| small screen | The diff becomes a single-column change list. | Every record and the confirm button stay in the tab order. |
| keyboard only | The wizard and the typed dialog work without a pointer. | Tab reaches the export, the revoke and the confirm actions. |

## Instrumentation

- `AUD-domain.decommissioned` records the removal with the end state and the actor.
- `AUD-tls.cert_revoked` records each certificate revocation with its names.
- `AUD-dns.record_exported` records the zone export used as the backup.

## Success and checks

Success: the domain is removed, the zone export and revert text survive the removal and the report shows no dangling record left behind. Checks: AC-37.
