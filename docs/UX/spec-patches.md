# Proposed specification screens

Status: proposal only. The ids below are **not** screens of the B12.1 screen table; they are recorded here so that a
journey which needs one can say so honestly, and so the gap reaches the specification instead of being hidden in a
route table. The highest existing B12.1 id today is S-148, so the proposals start at S-149.

| Proposed screen | Needed by | Reason | Status |
| --- | --- | --- | --- |
| S-149 | J-08, J-09, J-14, J-15 | The domain settings route (`/app/o/{org}/domains/{dom}/settings`) has no screen id in B12.1. The page groups DNS, proxy, TLS, origin and mode settings, and the add-domain journeys link to it after setup, so without an id the navigation and the journey maps cannot name it. | proposed |
