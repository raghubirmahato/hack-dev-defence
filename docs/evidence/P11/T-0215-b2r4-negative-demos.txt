# T-0215 batch B2 round 4 - negative (mutation) demos

For each finding: the fix seam is mutated back to its pre-fix form, the named test is run, the failure is recorded,
and the file is restored by `Copy-Item` from the external backup with the SHA-256 before = after. Equal hashes prove
the seam was the only change. The local prep helper (build + test signing + Smart App Control repair, see the red
file) runs between mutation and test only.
