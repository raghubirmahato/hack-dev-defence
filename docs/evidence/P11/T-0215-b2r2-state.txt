  asserts the closed eight codes and that `dependency_not_met`/`no_hdd_evidence` do not parse. A dependent of a non-PASS
  dependency is `UNVERIFIED(stage_not_reached)` with a `detail` naming the dependency id. `docs/ACCEPTANCE.md` drops the
  ninth-code deviation text and states the eight-code taxonomy.
* **R-1** `LoadProfile::allows_mode` (5 x 2 matrix) enforced in `RunnerConfig::build` **and** `Connector::new`;
  `ConfigError::ProfileModeMismatch`/`ConnectorError::ProfileModeMismatch`. Tests: config matrix + guard matrix.
* **R-2** `Report::resume_with(previous, resume_dir)` re-hashes every referenced evidence file inside the resume dir
  (path containment), binds the report to `config_revision`, target host names and a 24 h maximum age, refuses mismatch;
  `verify_evidence_inside` is shared with the executor; `Executor::set_resume` + `order_with_satisfied` make a resumed
  PASS satisfy dependencies (and the AC-00 gate). CLI `--config-revision` added; the old CLI test that codified
  `sha256="aaaa..."` now asserts the refusal, with a positive bound-resume test beside it.
* **R-3** `ConnectorParts`, `Connector::new`, `RateBudget::new`, `Limiter::new`, `CheckContext::new`, `AbortLatch::new`,
  `RunInvalidLatch::new` and `EvidenceRef::new` are `pub(crate)`; the executor builds the connector for the check via
  `CheckContext::connector(...)`; four `compile_fail` doc-tests hold the seal.
* **R-4** only `EvidenceStore` builds an `EvidenceRef` (hashing the bytes it wrote, no overwrite); the executor re-reads and
  re-hashes the evidence files inside the run's evidence root before accepting a PASS, else `FAIL(evidence invalid)`.
* **R-5** the inspect ticket is single-use (`consume`), TTL 30 s, digest over the actual verb, path, body hash and header
  hash, and the `config_revision` is re-read at send time; reuse/expiry/digest/verb/revision tests.
* **R-6** redaction handles spaces after the separator, quoted values (single/double) and tabs, failing closed to the end of
  the line; the exact review inputs are tested (`password = hunter2`, `password="my pass phrase"`, `token = abc def`,
  `secret=a<TAB>b`).
* **R-7** `PlannedRequest` has a short send window and is refused when stale; the budget token is spent at send, not at
  prepare; `Sender::send` takes the pinned addresses (no re-resolution, DNS rebinding).
* **R-8** a plan without AC-00 is `PlanError::MissingSelfTest`; AC-00 runs first and the run stops unless it ends PASS (the
  remainder is `UNVERIFIED(stage_not_reached)`); a target/stage guard denial latches `run_invalid` with an audit line and
  reaches the `RunReport` even when the check swallows the error; `Executor.panics` is carried into the `RunReport`.
* **R-9** the signal listener is primed (first poll) in the executor constructor; test asserts the poll happens before the
  first check.
* **R-10** expired grants are popped from the front on every acquisition; a 300k-grant lab test runs quickly and asserts the
  retained window is bounded.
* **R-11** `EvidenceStore` refuses overwrite, Windows reserved device names and NTFS streams; the truncation cap is exactly

* **R-12** redaction happens on field values before serialisation (no document-wide replacement; short secrets cannot corrupt
