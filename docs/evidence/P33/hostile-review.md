## Accepted or deferred, with a reason

- **15 (bus `Reconnected` is sent at the disconnect, not at the reconnect; queue overflow drops it).** Documented limitation: a change published between the subscriber's reload and the reconnect is caught by the revision gap on the next message. Needs a reconnect-complete signal from the client; ASM-033. UNVERIFIED without Redis.
- **19 (cluster slots).** The Exact log lives in `{key}:l`, a different slot from `key`: Redis Cluster would reject the script. HDD supports a single server or Sentinel (C18.10); a hash-tag key scheme is a change for the day cluster mode is wanted. ASM-033.
- **25b (secrets as plain `String`/arrays, R-03).** The generated passwords, the backup key and the Redis URL are ordinary strings today. They are never logged or placed on a command line, but they are not zeroized. Wrapping them in `secrecy` types belongs to the change that also gives them a lifetime (the supervisor, T-0564). ASM-031.
- **25c (R-22 and the database/Redis sockets).** Connections to the operator's own PostgreSQL and Redis are configured infrastructure, not requests built from caller data; they are not routed through the egress allowlist. ASM-032 states this reading of R-22 so the operator can overrule it.
- **25d (lexical symlink check, hard links).** `tar`'s own `unpack_in` refuses writes through links that leave the destination; the lexical check is the first line only. Hard-link reads inside the destination are harmless here.
- **6 (roles and grants in a restore).** Until T-0105 creates roles, a one-database dump is complete. ASM-030.

## Areas the reviewer found sound

Checksum before extraction with a compiled-in manifest and a size cap; the backup AEAD framing (nonce, index, end flag; reorder, truncate and extend detection); no password on a command line or in an environment variable; `pg_hba` and `listen_addresses`; the arithmetic of `rate.rs` against `LUA_RATE`; the Redis URL policy and redaction; creation-only TTL in the other scripts; key construction that rejects `:` in parts.
