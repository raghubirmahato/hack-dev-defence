## Phase introduction (verbatim)

Requirement prefix `NTF`. Goal: make HDD tell people what matters, where they already work, and make everything scriptable: the alert-rule engine and routing, integration channels, a reliable webhook delivery engine with signing, the complete public API v1 with governance, a Rust SDK and generated clients, developer documentation, and log forwarding to SIEM tools.

Non-negotiables: alerts are deduplicated and rate limited so an attack cannot flood owners' channels (alert-flood control is a security feature); every outbound call uses the central egress client with the SSRF guard; secrets for channels are write-only and encrypted; webhook payloads and notifications never contain request bodies, cookies, credentials or full IPs beyond the org's truncation setting; the public API is versioned with a deprecation policy, and the OpenAPI document is the single source of truth for the API reference, SDK and contract tests.

Gate G24 passes when: alert rules route correctly with dedupe, quiet hours and escalation; all channel integrations pass contract tests against local fakes (and live smoke tests where the operator supplied test destinations); webhooks are signed, retried and idempotent; the API contract tests and breaking-change detector pass; the SDK passes its integration tests; and AC-45 passes.
