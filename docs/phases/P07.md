## Phase introduction (verbatim)

Requirement prefix `APP`. Goal: the signed-in experience: frame, navigation, overview, notifications, command palette, onboarding checklist, org settings, plan and usage, audit log UI, help and announcements. Everything reads real data; where no data exists the screen shows an honest empty state (R-16). Metrics shown on the overview come from rollups (T-0140) that exist before the data plane does, so they initially show "No traffic yet".

Gate G07 passes when: the app shell and all P07 screens pass the UI verification suite (axe, keyboard, reflow, visual, performance), permission-filtered navigation is verified for every role, the command palette never leaks other tenants' data (BOLA tests extended), and the capability matrix rows for REQ-APP are linked to passing tests.
