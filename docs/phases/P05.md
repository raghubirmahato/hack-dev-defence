## Phase introduction (verbatim)

Requirement prefix `PUB`. Goal: the honest, fast, accessible public surface: landing, features, how protection works (with limits), docs, API reference, status, legal, contact and disclosure. It works with JavaScript disabled, sets only essential cookies, loads no third-party resources, and publishes nothing that depends on operator-owned text until supplied.

Gate G05 passes when: every public page passes axe (zero serious/critical), keyboard, reflow and performance checks and works with JavaScript disabled; the network trap sees no third-party requests; only essential cookies are set; claims-lint, docs check, link check and i18n check pass; the evidence-driven claims display correctly with and without evidence; the legal guard and signup gating behave when legal text is unresolved; and the gate report lists every UNVERIFIED item (screen-reader checks, operator legal text, external status hosting).
