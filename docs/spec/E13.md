### E13.3 Critical path

The longest dependency chain for the headline promise (vulnerable site protected, attacker banned, proven in the lab) is: T-0001 to T-0010 (governance) → T-0029 to T-0052 (design system) → T-0071 to T-0094 (frontend foundation) → T-0105 to T-0136 (identity) → T-0153 to T-0176 (onboarding) → T-0207 to T-0220 (walking skeleton) → T-0239 to T-0262 (WAF core) → T-0263 to T-0284 (SQLi shield) → T-0315 to T-0332 (bans) → T-0353 to T-0374 (proxy pipeline) → T-0405 to T-0416 (origin protection and outbound) → T-0491 to T-0499 (acceptance and Vuln-Lab proof). Everything else hangs off this chain and can run in the lanes above. The shortest path to something the operator can run on one computer is the local walking skeleton (slice DS1, E13.5): T-0561 to T-0563 → T-0564 → T-0568, with the identity, frontend and SQLi-shield tasks that those depend on.
