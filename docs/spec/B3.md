## B6. API catalog (`hdd-api`, JSON over HTTPS, base `/api/v1`)

### B6.1 Conventions

- Shorthand: `O` = `/api/v1/orgs/{org}`; `D` = `O/domains/{dom}`; `P` = `/api/v1/platform`. Org is addressed by slug or `org_` id; domain by `dom_` id.
- Auth: browser sessions (cookie, CSRF header on mutations) are accepted **only** on the same-origin mounts `app.{{PLATFORM_DOMAIN}}/api/v1/*` and `admin.{{PLATFORM_DOMAIN}}/api/v1/*` (B2.1). `Authorization: Bearer hdd_<prefix>_<secret>` API keys are the only credential accepted on `api.{{PLATFORM_DOMAIN}}`. Public routes are marked `public`.
- Errors: RFC 9457 `application/problem+json` with `type` = `https://docs.{{PLATFORM_DOMAIN}}/errors/<slug>`, `code` = `ERR-...` (B7), `request_id`, optional `errors[]` with JSON-pointer field paths. No stack traces, no internal hostnames.
- Pagination: cursor (`?limit=50&cursor=...`, max 200); response `{data:[...], next_cursor}`. Filters are explicit query parameters; unknown parameters are rejected with `ERR-VAL-002`.
- Concurrency: `ETag` on GET of mutable resources, `If-Match` required on PATCH/PUT/DELETE of those resources (`ERR-CONC-001` on mismatch, `428` if missing). Idempotency: `Idempotency-Key` header on every POST that creates a resource or triggers a job.
- Rate limit classes: `auth` (strict), `read`, `write`, `export`, `stream`, `public`. Responses carry `RateLimit-Limit`, `RateLimit-Remaining`, `RateLimit-Reset`, and `Retry-After` on 429.
- Streaming: Server-Sent Events with `Last-Event-ID` resume; heartbeat comment every 15 s; per-connection bounded buffer; a slow consumer is disconnected, not buffered without bound.
- Versioning: the path version is stable; breaking changes require `v2`. Deprecations carry `Deprecation` and `Sunset` headers and a changelog entry.
- Every endpoint below has: OpenAPI entry, permission check, audit event where it mutates, metric, and a generated contract test (rule in section 0.7 `[API]`).
